# 风格卡 · The Astral Archive（时空剧场）

> 本卡是**锁风格**用的：任何新美术物料（角色、场景、卡牌、UI、转场）都必须以本卡的锚点图为参考做图生图，不得自由发挥。风格卡一旦确认，本项目不再更换。
> 关联：`assets/original-art-plan.json`（待生产物料清单）、`DESIGN.md`（UI 令牌）、`assets/asset-ledger.json`（权属台账）。

## 一、品类与画幅（锁死，改了整套返工）

| 项 | 规格 |
|---|---|
| 品类 | 初中历史互动叙事游戏（学习产品优先，游戏层其次） |
| 主角视角 | 2.5D 舞台式：角色立绘（半身/全身）+ 单层场景底图 + 前景遮挡层 |
| 画幅 | 场景 16:9（1920×1080 基准，交付 1280×720 WebP）；角色立绘 3:4（交付 864×1152 WebP）；卡牌 512×716 |
| 色调基调 | 深空蓝夜幕 + 炼金金高光 + 冷蓝玻璃界面 |
| 禁止 | 写实摄影感、赛博霓虹、Q 版搞笑向、血腥写实 |

## 二、三个候选方向（评审时三选一，锚点图按选定方向产出）

**方向 A · 星轨档案（推荐）**
深蓝夜幕中的悬浮档案馆，金线把散落的历史碎片串成轨道，玻璃与铜金材质，光源单一来自上方金色星轨。冷静、克制、有"学术权威感"。

**方向 B · 戏台幻影**
以中国戏台/西式剧场幕布为框架，角色像皮影与全息投影叠在幕布之间，暖红与金为主、背景仍是深蓝。戏剧性最强，但可能压过"学习"气质。

**方向 C · 纸本文脉**
宣纸与线装书质感叠加星空，古籍插画 + 缂丝纹样，色彩偏米金与靛青。学术感最强，但与"科幻感的星轨设定"冲突较大。

> 评审要求：先看三张**风格锚点图**（各 1 张，同一场景同一构图，只换风格），选定后只出该方向的锚点图一张。

## 三、风格卡（六项规格）

| 项 | 规格 |
|---|---|
| 主色 | 底 `#041133`（深空蓝）/ 层 `#0D1A3C` / 组件 `#121E40` / 高亮 `#2D385B`；主金 `#EFBD8A`，金容器 `#5A3912`；次蓝 `#B6C4FF`；角色粉 `#FFB2B8`、洛书橙 `#FF8C42` |

| 禁止项 | 纯黑/纯白大色块、90° 硬角、赛博霓虹、真实照片质感、任何外部 IP 角色特征、水印与文字 |

## 四、锚点清单（先锚点，再量产）

| 锚点 | 内容 | 用途 |
|---|---|---|
| A1 风格锚点 | 同一场景（星轨档案馆内景，16:9），按选定方向绘制 | 所有场景、UI 背景、转场的风格基准 |
| A2 角色锚点 | 子衿，正面全身设定卡（3:4），含色板与表情索引 | 子衿/洛书全部差分与换装的基准 |
| A3 卡牌锚点 | 一张金框卡（含 ornate 左上角），512×716 | 全部卡牌插画基准 |
| A4 场景层锚点 | 同一场景的远/中/近三层分解图 | 所有场景三层视差基准 |

> 规则：**锚点未确认不批量**。任何一次批量产出后必须逐张目视复核风格一致性与主体保真，读不到一致就返工。

## 五、表情差分清单（当前是"同图复制"，必须做真差分）

| 角色 | 表情 | 情绪映射（引擎 `emotionToExpression`） |
|---|---|---|
| 子衿 | normal / serious / excited / curious / thinking / sad | calm→normal, serious→serious, excited→excited, thinking→thinking, sad→sad |
| 洛书 | normal / solemn / thinking / sad / excited | 同上，solemn 为洛书专属 |
| 剧本角色（5 人） | normal / serious / thinking / sad | 依据 `data/npc_personas.json` 的 `emotion_library` |

> 引擎侧已支持情绪→表情回退（`engine.js` 的 `CHAR_EXPR_FALLBACK`），所以**即使某张差分缺失也不会破图**，但情绪表现会退化——这正是要补真差分的原因。
