## 300 字版（项目介绍栏）

> **痛点**：初中历史最难的不是记忆，是理解因果。学生能背「1776 年《独立宣言》」，却分不清根本原因、导火线和开始标志。老师清楚这个坑，但 40 分钟一节课，没时间为每个学生单独拆解。
>
> **做法**：**时空剧场 AI 导学版**把历史做成可玩的剧本——学生不是读课本，是在关键节点做决定、承担后果，每个选择都挂着知识点，答错会指出错在哪一层（史实层 / 因果层）。目前有五个剧本，覆盖八九年级核心近代史：美国独立战争、法国大革命、工业革命、戊戌变法、辛亥革命。
>
> **教师侧是真正的差异点**：老师选课时（15/20/40 分钟）、学生基础、教学重点和使用方式，AI 读取该剧本的**真实幕次结构与知识点图谱**，输出一份可直接执行的导学卡——保留哪几幕、每幕分配几分钟、**为什么值得占用课堂时间**、中途在哪停下来提问、板书提纲怎么列。这不是通用 PPT 生成，是针对这个具体剧本的课堂编排。
>
> **工程可靠性**：AI 调用做了主模型 → 备用模型 → 规则模板三层降级，断网也能出一份可用教案——课堂上老师不能等。
>
> **合规**：面向未成年人，全程匿名免注册；只采集事件白名单内的产品行为，payload 字段亦按白名单裁剪；**采集默认关闭**，需明示同意方开启。
>
> **技术**：Node 22 内置 HTTP + 内置 SQLite，运行时零 npm 依赖，单进程 systemd 部署，冷启动 3 秒。

## 亮点提炼（评委记忆点，挑 3 条讲）

1. **AI 排的是「这一节课」，不是「一份资料」** —— 读真实幕次结构，输出可执行编排，每幕都有为什么。
2. **三层降级，永不空手** —— 主模型 → 备用模型 → 规则模板。课堂不能等 AI。
3. **默认不采集** —— 面向未成年人，白名单 + 默认关闭 + 全程匿名，合规不是补丁是默认值。
4. **零运行时依赖** —— Node 内置能力搞定 HTTP 与数据库，学校自己的旧服务器也能跑。
5. **换模型改一行** —— OpenAI 兼容协议，不绑定任何供应商。
