## 1. 部署架构

```mermaid
graph TB
    subgraph Client["用户侧"]
        S["学生浏览器<br/>进度存 localStorage"]
        T["教师浏览器"]
        A["管理员浏览器"]
    end

    subgraph ECS["阿里云 ECS · 8.148.245.29"]
        NG["Nginx :443<br/>TLS 终止 + 安全头"]
        subgraph APP["systemd: time-theater.service"]
            NODE["Node 22 内置 HTTP<br/>127.0.0.1:8787<br/>运行时零 npm 依赖"]
        end
        DB[("node:sqlite<br/>/srv/time-theater/data")]
    end

    subgraph LLM["外部 AI 供应商"]
        P1["主：OpenCode<br/>deepseek-v4-flash"]
        P2["备：MiniMax<br/>MiniMax-M2.5"]
    end

    S -->|https://awkn.cn/game/| NG
    T --> NG
    A --> NG
    NG -->|"location ^~ /game/<br/>proxy_pass :8787"| NODE
    NODE --> DB
    NODE -.->|OpenAI 兼容协议| P1
    P1 -.->|失败时| P2
    P2 -.->|再失败| RULE["规则模板<br/>本地 JSON"]
    NODE --> RULE
```

**关键点**

- Node 只监听 `127.0.0.1:8787`，**不暴露公网**，全部流量经 Nginx
- `proxy_pass http://127.0.0.1:8787/` 尾部斜杠剥离 `/game` 前缀，服务端按根路径工作
- 数据目录 `/srv/time-theater/data` 独立于 release 目录，**版本切换不丢数据**
- 发布用 `releases/<时间戳>` + `current` 软链，原子切换、秒级回滚

## 2. AI 三层降级链路

```mermaid
flowchart LR
    REQ["POST /api/v1/teaching-assistant"] --> CHK{"AI_ENABLED<br/>且有密钥?"}
    CHK -->|否| RULE
    CHK -->|是| P1["① 主：OpenCode"]
    P1 -->|200 且 JSON 合法| OK["mode: ai<br/>provider: primary"]
    P1 -->|超时/限流/格式坏| P2["② 备：MiniMax 直连"]
    P2 -->|200 且 JSON 合法| OK2["mode: ai<br/>provider: fallback"]
    P2 -->|再失败| RULE["③ 规则模板<br/>data/rule_templates.json"]
    RULE --> OUT["mode: rule<br/>仍返回可用教案"]
    OK --> LOG[("写入 ai_runs<br/>记录 mode/耗时/错误码")]
    OK2 --> LOG
    OUT --> LOG
```

**鲁棒化处理**（踩过的坑，都在代码里）

| 问题 | 处理 |
|---|---|
| 推理模型返回 `<think>...</think>` 包裹思考过程 | `stripThink()` 剥离后再解析 |
| 返回带 Markdown 代码围栏 | `extractJson()` 提取围栏内 JSON |
| 数组字段返回成字符串 | `coerceArray()` 强制转数组 |
| 缺 `title` / `actions` 不足 3 项 | `normalize()` 按任务补齐 |
| 供应商瞬时抖动 | 主备自动切换，全失败才落规则 |

> 后台 dashboard 的 `aiRuleFallbackToday` 直接暴露降级次数——
> 这个数字为 0 说明当天 AI 全部真调用成功。

## 3. 数据与隐私流

```mermaid
flowchart TB
    ACT["学生互动<br/>进幕/选择/答题"] --> HOOK["engine.js GameHooks<br/>8 类正式钩子"]
    HOOK --> CONSENT{"用户已明示同意?<br/>默认 false"}
    CONSENT -->|否| DROP["丢弃，不上传<br/>本地进度不受影响"]
    CONSENT -->|是| WL{"在事件白名单内?<br/>event_catalog.json 18 类"}
    WL -->|否| REJ["EVENT_NOT_ALLOWED"]
    WL -->|是| SAN["payload 按 allowedPayloadKeys 裁剪<br/>未列字段一律丢弃"]
    SAN --> POST["POST /api/v1/events/batch"]
    POST --> PE[("product_events<br/>匿名 ID，无姓名/手机/IP 明文")]
    PE --> ADMIN["管理后台<br/>匿名时间线"]

    LOCAL["完整学习进度"] -.->|"始终只在本机<br/>不上传"| LS[("浏览器 localStorage")]
```

**三重最小化**

1. **默认关闭** —— `isTrackingEnabled = false`，不同意一条不传
2. **事件白名单** —— 只有 `event_catalog.json` 列出的 18 类事件名能进
3. **字段白名单** —— 每类事件再按 `allowedPayloadKeys` 裁剪 payload

完整学习进度（答题记录、错题、知识掌握度）**始终只存浏览器本地**，服务端从不接收。

## 5. 技术选型理由（评委常问）

| 选择 | 理由 |
|---|---|
| Node 内置 `http` 而非 Express | 运行时零依赖，无供应链风险，学校内网也能装 |
| `node:sqlite` 而非 better-sqlite3 | Node 22 内置，**无需编译原生模块**，部署不挑机器 |
| 单进程 systemd 而非 Docker | 目标用户是学校 IT，一条 `systemctl` 比一套 Docker 好维护 |
| OpenAI 兼容协议 | 换供应商只改环境变量，不绑定任何厂商 |
| JSON 配置驱动内容 | 加剧本 = 加 JSON + HTML，代码零学科硬编码 |
| 进度存 localStorage | 免注册的前提；也是隐私最小化的结构性保证 |
