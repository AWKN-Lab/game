## 三、3 分钟演示脚本（逐字稿 + 操作）

### 0:00–0:20 　开场：问题是什么

> 「初中历史课最难的不是记不住，是**理解不了因果**。
> 学生背下'1776 年独立宣言'，但说不清根本原因、导火线、开始标志的区别。
> 老师知道这个坑，但一节 40 分钟的课，没时间给每个学生单独讲。」

**操作**：停在首页，不动。

### 0:20–1:00 　学生视角：玩进去，而不是背下来

**操作**：点「美国独立战争」→ 快速走 2 个选择 → 触发一次知识卡 → 答 1 道题。

> 「学生不是在读课本，是在做决定。
> 每个选择背后都挂着知识点，答错会立刻告诉他**错在哪一层**——
> 是史实记错了，还是因果关系搞反了。
> 五个剧本：美国独立战争、法国大革命、工业革命、戊戌变法、辛亥革命，
> 覆盖初中八九年级的核心近代史。」

### 1:00–1:50 　教师视角：AI 导学卡（**核心亮点**）

**操作**：回首页 → 「教师导学卡」→ 选「美国独立战争 / 40 分钟 / 中等基础 / 投屏使用」→ 生成。

> 「这是老师的入口。选课时、学生基础、教学重点，
> AI 会把这个剧本**重新编排成一节可上的课**——
> 哪几幕留、每幕几分钟、为什么留、中间在哪停下来提问、板书怎么写。
> 注意这不是通用模板，它读的是这个剧本的真实幕次结构。」

**指着结果说**：
- `recommendedActs`：每幕都有 **reason**，说明为什么这一幕值得占用课堂时间
- `pauseQuestions`：停顿提问，直接对着常见错误设计

### 1:50–2:30 　数据视角：老师看得见每个学生

**操作**：切到管理后台 → dashboard → 点「互动事件」。

> 「所有学生的互动都在这里：进了哪一幕、做了什么选择、测试对几道。
> 全程**匿名**——没有姓名、没有手机号、没有登录。
> 只采集白名单里的 18 类产品行为，
> 而且**默认关闭**，学生不点同意就一条都不上传。」

**指着 dashboard 说**：`aiRuleFallbackToday: 0` —— 「今天所有 AI 请求都真调用成功了，零降级。」

### 2:30–3:00 　收尾：可靠性

> 「最后说一句工程上的事。
> AI 会挂——超时、限流、返回格式坏掉。
> 我们做了**三层**：主模型 → 备用模型 → 规则模板。
> 断网也能出一份能用的导学卡，只是不那么个性化。
> 课堂上老师不能等，产品必须永远有输出。」

**操作**（可选，见 §四）：现场演示降级。

**方式 B — 真断，效果强**（需提前彩排）：

```bash

ssh root@8.148.245.29 'cd /srv/time-theater/current && cp .env .env.demo.bak && \
  sed -i "s|^AI_ENABLED=.*|AI_ENABLED=false|" .env && systemctl restart time-theater'

# 2) 现场再点一次「生成导学卡」→ 仍然出结果，响应里 mode = "rule"

# 3) 立刻恢复（务必！）

  systemctl restart time-theater && sleep 3 && \
  curl -sk https://127.0.0.1/game/api/v1/health/ready -H "Host: awkn.cn"'
```

> 恢复后必须看到 `aiConfigured:true` 才算复原。

## 五、应急预案

| 症状 | 判断 | 处理 |
|---|---|---|
| 页面打不开 | 先试 `https://awkn.cn/win/`（兄弟站点） | 兄弟站点也挂 → 服务器/网络问题；只有 `/game/` 挂 → 下一行 |
| `/game/` 502 | Node 服务挂了 | `ssh root@8.148.245.29 'systemctl restart time-theater'`，5 秒恢复 |
| AI 生成转圈超 30 秒 | 主备都超时 | 等，会自动落到规则模板出结果；**顺势讲降级设计** |
| 后台登录 401 | 会话过期（12h） | 重新登录 |
| AI 结果内容怪 | free 档模型抖动 | 重新生成一次；或改讲规则模板版本 |
| 全线崩 | — | 切本地：`cd D:\awkn-lab\game && npm start` → `http://127.0.0.1:8787/` |

**一键回滚到旧静态版**（最后手段，会丢 AI 功能但页面能开）：

```bash
ssh root@8.148.245.29 'ls /srv/time-theater/backups/awkn.cn.conf.bak.*'
ssh root@8.148.245.29 'cp /srv/time-theater/backups/awkn.cn.conf.bak.<ts> /etc/nginx/conf.d/awkn.cn.conf && nginx -t && nginx -s reload'
```

## 六、评委高频问题（准备好的答案）

**Q：AI 用的什么模型？自己训的吗？**
A：不是自训。主用 OpenCode 托管的 deepseek-v4-flash，备用 MiniMax-M2.5 直连，OpenAI 兼容协议，换供应商只改一行环境变量。我们的工作在**提示词工程 + 输出契约 + 降级链路**——保证输出永远是能直接用的结构化教案，而不是一段散文。

**Q：数据合规怎么做的？面向未成年人。**
A：三条：① 全程匿名，无注册、无姓名手机号；② 事件白名单制，只有 `data/event_catalog.json` 里的 18 类行为能上传，payload 字段也按白名单裁剪；③ **采集默认关闭**，需明示同意才开。详见 `docs/demo/03-隐私与AI说明.md`。

**Q：老师要培训多久才会用？**
A：零培训。教师入口只有 4 个下拉框：课时、学生基础、教学重点、投屏还是自学。点一下出教案。

**Q：为什么不用现成的 AI 课件工具？**
A：通用工具生成的是「关于美国独立战争的 PPT」。我们生成的是「**这个具体剧本**在 40 分钟里怎么排」——AI 读的是剧本的真实幕次结构和知识点图谱，输出能直接对应到学生下一步会点到的那一幕。

**Q：技术栈？部署重不重？**
A：很轻。Node 22 内置 HTTP + 内置 `node:sqlite`，**运行时零 npm 依赖**。一台 2 核云服务器，systemd 起一个进程，Nginx 反代。整站冷启动 3 秒。

**Q：能扩到其他学科吗？**
A：能。剧本、知识点、题库、提示词全是 JSON 配置，代码不含任何学科硬编码。加一个剧本 = 加一份 JSON + 一个 HTML。
