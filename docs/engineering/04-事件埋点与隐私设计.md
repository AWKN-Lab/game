# ENG-04｜事件埋点与隐私设计

> 状态：已确认  
> 版本：V1.0  
> 核心原则：管理员看到全部“已定义产品互动”，不做录屏式监控。

---

# 一、目标

事件系统服务三个目的：

1. 还原用户在产品中的真实学习路径；
2. 找到剧本、选择、答题、AI 和页面中的具体卡点；
3. 为反馈、许愿和产品路线图提供证据。

事件系统不服务：

- 广告定向；
- 未成年人商业画像；
- 设备指纹追踪；
- 站外行为追踪；
- 屏幕录像；
- 键盘监听；
- 未主动提交的私人文本采集。

# 二、事件模型

每条事件统一包含：

```json
{
  "eventId": "01J...",
  "name": "choice_selected",
  "occurredAt": "2026-08-04T08:00:00.000Z",
  "actorId": "uuid",
  "sessionId": "uuid",
  "role": "student",
  "page": "american_revolution.html",
  "scriptId": "american_revolution",
  "payload": {},
  "schemaVersion": 1
}
```

## 公共字段

| 字段 | 必填 | 来源 | 说明 |
|---|---|---|---|
| eventId | 是 | 客户端 | 幂等 ID |
| name | 是 | 客户端 | 事件目录中的名称 |
| occurredAt | 是 | 客户端 | 发生时间 |
| actorId | 是 | IdentityClient | 随机匿名 ID |
| sessionId | 是 | IdentityClient | 本次会话 ID |
| role | 是 | 页面入口 | student/teacher/unknown |
| page | 是 | location | 仅相对页面名 |
| scriptId | 否 | 页面/引擎 | 剧本 ID |
| payload | 是 | 事件调用方 | 白名单字段 |
| schemaVersion | 是 | SDK | 当前为 1 |

服务端自行补充：

- receivedAt；
- traceId；
- clientVersion；
- deviceClass；
- locale；
- 校验状态。

---

# 三、事件命名规则

格式：

```text
<object>_<past-tense-action>
```

示例：

- `page_viewed`
- `script_started`
- `choice_selected`
- `quiz_answer_submitted`
- `wish_created`

禁止：

- `click_button_1` 这类无业务语义名称；
- 把用户自由文本拼进事件名；
- 按页面临时创造无法复用的同义事件；
- 事件名称包含中文、空格或版本号。

# 五、事件 SDK 设计

## 5.1 公共 API

```js
EventClient.init({
  endpoint: '/api/v1/events/batch',
  clientVersion: window.APP_VERSION,
  enabled: true
});

EventClient.track('choice_selected', {
  nodeId: 'ar_choice_001',
  actId: 'act_1',
  choiceId: 'observe',
  choiceIndex: 1,
  timed: false,
  elapsedMs: 8200
});
```

## 5.2 队列优先级

### critical

- script_completed
- quiz_completed
- lesson_plan_generated
- learning_review_generated
- feedback_created
- wish_created

### normal

- choice_selected
- evidence_opened
- card_used
- knowledge_opened

### low

- page_viewed
- dialogue_progressed
- card_viewed

队列满时先丢 low，再丢最旧 normal，critical 最后丢弃。

## 5.3 重试

```text
立即发送失败
→ 5秒
→ 15秒
→ 30秒
→ 1分钟
→ 5分钟封顶
```

遇到 400/413/422 不重试；遇到 429 服从 `Retry-After`；网络错误和 5xx 重试。

## 5.4 页面离开

- 优先 `navigator.sendBeacon`；
- 不支持时用 `fetch(..., {keepalive: true})`；
- 发送失败保留本机队列；
- 不阻止页面关闭。

# 六、隐私控制

## 6.1 数据改进开关

设置入口：

```text
设置
→ 数据与隐私
→ 帮助改进时空剧场
```

默认策略：

- 比赛演示环境可默认开启并明确提示；
- 正式未成年人环境应按产品合规评估决定默认值；
- 无论默认值如何，用户都能关闭；
- 关闭后立即停止普通事件入队，并清空未发送普通事件；
- 用户仍可主动提交反馈和愿望。

## 6.2 匿名身份

使用：

```js
crypto.randomUUID()
```

禁止使用：

- Canvas 指纹；
- 字体指纹；
- 硬件组合哈希；
- IP + User-Agent 生成永久身份；
- 邮箱或手机号作为匿名 ID。

## 6.3 自由文本

自由文本只在以下主动操作中提交：

- 教师输入教学重点；
- 用户提交反馈；
- 用户提交愿望；
- 管理员回复和内部备注。

普通埋点不复制自由文本正文，只记录长度、类别和关联资源 ID。

## 6.4 管理员可见范围

管理员互动时间线可以看到：

- 页面和剧本路径；
- 关键选择 ID；
- 证据、卡牌和知识点 ID；
- 答题选项 ID 和对错；
- AI 任务状态和结果摘要；
- 用户主动提交的反馈和愿望。

管理员看不到：

- 浏览器密码；
- 完整 localStorage；
- 屏幕内容；
- 键盘输入过程；
- 其他网站访问；
- 未提交的表单草稿；
- AI Key；
- 管理员 Session Token。

# 七、事件 Schema 管理

事件目录文件：

```text
data/event_catalog.json
```

示例：

```json
{
  "version": 1,
  "events": {
    "choice_selected": {
      "priority": "normal",
      "required": ["nodeId", "choiceId", "choiceIndex"],
      "properties": {
        "nodeId": {"type": "string", "maxLength": 100},
        "actId": {"type": "string", "maxLength": 100},
        "choiceId": {"type": "string", "maxLength": 100},
        "choiceIndex": {"type": "integer", "minimum": 0, "maximum": 20},
        "timed": {"type": "boolean"},
        "elapsedMs": {"type": "integer", "minimum": 0, "maximum": 3600000}
      },
      "adminVisible": ["nodeId", "actId", "choiceId", "choiceIndex", "timed", "elapsedMs"]
    }
  }
}
```

前端与服务端从同一目录生成/加载校验规则，避免字段口径漂移。

新增事件必须同时完成：

1. 业务目的；
2. 触发时机；
3. Schema；
4. 隐私评估；
5. 管理端展示方式；
6. 自动测试；
7. 保留期。

# 八、数据质量

管理员看板同时显示数据质量指标：

- 事件接收数；
- 拒绝数；
- 重复数；
- 未知事件名；
- Schema 版本分布；
- 客户端版本分布；
- 延迟超过 10 分钟的事件；
- 队列丢弃事件；
- session 无 actor；
- event 无 session。

质量规则：

- 拒绝率 > 1%：发布阻断；
- 未知事件 > 0：检查版本兼容；
- critical 事件缺失率无法直接测量时，用脚本完成与完成事件比对；
- 时间戳偏差超过 24 小时，使用 receivedAt 并标记。

# 九、验收用例

1. 新用户首次进入生成匿名 ID，不产生设备指纹；
2. 同一标签页刷新保持 actorId，创建新 sessionId；
3. 无网络完成剧本后事件进入本机队列；
4. 恢复网络后事件按 eventId 去重上传；
5. 选择事件不包含完整选项文本；
6. 答题事件不包含姓名和完整题面；
7. 关闭数据改进后普通事件停止；
8. 关闭后仍能主动提交反馈和愿望；
9. 管理员时间线按 occurredAt 正确排序；
10. 管理员无法通过接口获取未在 adminVisible 中声明的 payload 字段；
11. 队列满时按优先级丢弃；
12. event 接口 500 不影响剧情推进；
13. 发送重复 eventId 不重复入库；
14. 非目录事件被拒绝并记录数据质量指标；
15. 自由文本不会出现在普通事件和应用日志。
