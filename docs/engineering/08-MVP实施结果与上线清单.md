# 三、上线前仍需外部环境完成

以下事项无法通过 Git 仓库自动完成，需要拥有服务器和百炼业务空间权限的人执行。

## 3.1 服务器环境

- [ ] 确认服务器 Node.js `>= 22.5.0`；
- [ ] 确认 Nginx 已安装；
- [ ] 确认 systemd 可用；
- [ ] 创建 `releases` 与 `shared` 目录；
- [ ] 将 `deploy/nginx/time-theater.conf` 合并到生产配置；
- [ ] 安装 `deploy/systemd/time-theater.service`；
- [ ] 确认服务用户对 `shared/data`、`shared/backups`、`shared/logs` 有写权限。

## 3.2 生产环境变量

复制 `.env.example` 到：

```text
/www/wwwroot/awkn-lab/game/shared/.env
```

至少确认：

- [ ] `PUBLIC_ORIGIN` 为正式域名；
- [ ] `DB_PATH` 指向共享目录；
- [ ] `COOKIE_SECURE=true`；
- [ ] `ADMIN_EMAIL` 不使用示例值；
- [ ] `ADMIN_PASSWORD` 为强密码；
- [ ] `DASHSCOPE_API_KEY` 已配置；
- [ ] `AI_BASE_URL` 使用实际业务空间地址；
- [ ] `AI_MODEL` 已确认可调用。

## 3.3 管理员初始化

```bash
cd /www/wwwroot/awkn-lab/game/current
npm run db:migrate
npm run admin:seed
```

完成后：

- [ ] 删除 `.env` 中临时的管理员明文密码，或转为部署系统密钥；
- [ ] 登录管理员后台；
- [ ] 退出后确认 Session 已失效；
- [ ] 连续错误密码确认触发限流。

## 3.4 首次发布

```bash
bash scripts/deploy.sh
```

发布后检查：

- [ ] `/api/v1/health/live` 返回 200；
- [ ] `/api/v1/health/ready` 返回 200；
- [ ] `/` 打开 AI 导学版；
- [ ] 五个剧本均可进入；
- [ ] 教师导学卡显示 AI 版；
- [ ] 临时关闭 AI 后显示规则版；
- [ ] 学生复盘能读取已有本机数据；
- [ ] 反馈能提交；
- [ ] 愿望能提交；
- [ ] 管理员能看到事件、反馈和愿望；
- [ ] 回滚脚本完成一次演练。
