# ENG-10｜首批真实试用采集口径

> 版本：V1.1（设计修订提案，待评审）
> 2026-11-28：旧版 P2 样本中位数一半判据废止，全部试用按 [ENG-12](./12-历史耦合修复与C实验工程落地.md) 及 [ENG-13](./13-历史探究实验与数据验收契约.md) 执行。下文区分现有事件与拟新增契约，未声明已上线。

## 一、试用阶段

- 合成账号 E0：先验证版本、事件传输、存档、弱网及安全门禁，不接触儿童真实数据。
- 首位学生和 E1（建议 6–10 人）：检查任务理解、史料阅读负荷、主动行动、情感连接、错误恢复与弱网；不推断群体效果或 P2 立项。
- E2：在预注册后比较 B0/C1（数字同媒介）及教师阅读 T（学习参照）；人数按最小有意义差异与设计计算。真实儿童试用须先获得适用的家长授权、学生同意、学校批准，并落实退出机制与数据最小化。
- 初始一节课 40–45 分钟及 10–15 分钟探究单元仅为设计场景，实际时间由教师和 E1 验证。先确认目标年龄及历史知识前置条件。

## 二、指标字典

| 指标 | 口径 | 证据与限制 |
|---|---|---|
| 触达 | 时间窗内去重匿名 actor 数，按页面分层 | page.view；仅可观察同意上传的覆盖人群 |
| 剧本进入率 | 有 script.start 的去重会话 / 首页有效会话 | 现有口径；需单列页面直达等不适用路径 |
| 故事完成率 | 分配/开始 attempt 中首次 story_complete 的比例 | ENG-13 新契约；legacy 会话单列，不混算 |
| 幕级漏斗 | 按同一 attempt 去重 actId / 已开始 attempt | 新契约；幕次重复访问不重复计算 |
| 中断与续玩 | 最后观察幕、最后活动时间、后续恢复状态 | 20 分钟无事件只标暂时不活跃；不直接判流失 |
| 自主参与 | 有等同自主机会者中主动开始可选续玩或回访者比例；当场与7日分别报告 | 机会记录＋观察；现有埋点无法单独证明无催促 |
| 学习增益 | 按随机分配组报告前测、即时后测、7日延迟保持与新史料迁移 | 外部独立题及盲评；失访按预注册处理 |
| 联合达标 | 有等同自主机会者中学习及乐趣同时达标的比例 | 辅助指标；分母、缺测、置信区间单列 |
| 答题与证据 | 首次答题正确率、证据面板打开、引用理由质量分别计 | quiz.answer / evidence_open 仅过程诊断；打开不证明阅读 |
| NPC 互动 | 对话次数、自由输入、信任变化、回响引用及规则降级分别报告 | 互动多可能源于困惑；分母与 AI 模式分层；不能单独证明需求 |
| 结局分布 | 有效故事完成 attempt 的 endingType 分布 | 每次完整重玩保留，测验事件不计故事结束 |
| 家长接受 | 支持再次使用、安全与时间接受度、负面意见 | 自愿匿名问卷或访谈；报告应答人数与缺失 |
| 教师接受 | 课程目标匹配、实际备课时间、课堂可执行性、再用意愿 | 教师记录及访谈；同时报告管理负担 |
| 安全/质量 | 事实错误、严重隐私事件、可访问性障碍、技术失败 | 按预注册停止条件处理；严重问题不得由高参与率抵消 |

## 三、现有埋点及兼容

现有 33 类事件以仓库 data/event_catalog.json、客户端白名单及服务端过滤器的实际版本为准；当前未有 session_started / session_ended 新契约，历史 script.ending 有 pending 和测验后两个阶段。历史数据无 attemptId 时只能做旧版诊断，标记 unknown；不得回填假 ID 或与新版完成率拼接。导演台、轻量模式事件可作为过程指标。规则降级与 AI 版分层报告，不将降级简单解释为儿童不喜欢。

## 四、形成性观察问题

先让孩子在自然场景体验；避免引导式提问。记录具体节点和行为，允许负反馈。

1. 哪一刻最想继续？哪一刻想离开？为什么？
2. 为了完成目标，自己找了什么历史信息？如果没找到，可以做什么？
3. 你为什么改变或坚持原来的判断？哪份材料支持它？
4. 角色反馈是否可信？有没有感觉系统在替你作答？
5. 哪些阅读、操作、音频或网络问题影响体验？你还有什么想探索？

观察记录仅使用研究编号与必要行为，不录屏式监控，不保存无关自由输入。未成年人退出不影响教学待遇。正式 E2 独立评估不提供答案提示。

## 五、决策

P2 IP 角色卡没有自动立项线。需独立的儿童需求信号、教育增益、权属、成本、家长/教师约束和可执行的竞争性原型证据。单人反馈或 NPC 互动指标只生成假设。C 结果仅支持相近探究单元的后续投资判断，不自动决定 A/B 或全部题材。试用报告须附版本、实际样本与机会覆盖、原始计数、缺失、负例、估计及不确定区间、独立复核意见和下一步决策。
