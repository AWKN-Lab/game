三方独立审计（第一性原理研究、体验深度分析、历史学习机制审计）收敛于同一判断：**工程资产扎实，但历史知识与通关机制耦合不足**。

**设计原则（V1.1 修订）**：历史知识应该帮助孩子解决问题，而非成为阻挡孩子继续游戏的障碍。允许孩子判断错误、承担后果、重新调查、修正认知；历史学习效果通过独立测评确认，不通过通关门禁确认。

# 三、P0 修复（S1 批次）

## FIX-0｜反事实测试重设计（替代原单一判据）

原"删掉史料仍能通关即不合格"可被强制点击伪耦合绕过，废止。每个历史学习单元验收改为三条反事实对照：

1. **保留信息、删证物形式**：历史信息改由其他渠道（NPC 台词、叙事）呈现，观察决策质量是否保持——保持则证物形式非承重；
2. **保留操作、删历史信息**：移除决策所需历史信息，同时保持操作、时长与反馈可用；比较决策质量、证据解释和新任务迁移。可继续操作属于允许行为；差异不足须分析既有知识、题目线索、操纵强度及样本不确定性；
3. **改变史实关键变量、保持操作**：在明确标为假设的研究变体中改变一项决策相关条件；预先定义哪些判断应调整、哪些应保持。若未出现预测差异，记录反证并区分理解不足、条件无关、材料不清或测量灵敏度不足；不得将伪造史实呈现为真实历史。

判定依据是**决策质量与独立理解评估**的差异，不是点击率或属性奖励。已有知识充分的孩子可直接判断并给出证据，不强制重复读卡。通关允许失败与纠错；掌握认证独立评估。

## FIX-1｜答案位置泄漏（F1，契约按 M2 升级）

**数据契约**：

- 每题稳定 `questionId`；每选项稳定 `optionId`；新增 `correctOptionId` 与 `contentVersion`
- 展示顺序由持久化的 `attemptId + questionId + contentVersion` 决定（确定性伪随机），不依赖可轮换的 sessionId 或动态 dialogIndex
- 判定、反馈、埋点全部使用 `optionId`；`correctIndex` 不再新增产生，显示索引仅作诊断
- 旧存档按旧内容版本映射旧位置；无法映射时该题重新进入，不猜测

**测试**（新增，进 `tests/`，并同步 `validate-events` 与服务端事件目录）：

1. 确定性：同 attemptId+questionId+contentVersion 下顺序稳定；跨 attempt 顺序变化
2. 分布阈值：预注册各位置出现比例的合格区间（"无显著偏斜"不作为通过标准）
3. 错误选项反馈一致性、保存续玩、跨标签页、重复选择
4. 可读性与键盘操作须真实浏览器验证，不以静态检查替代
5. 端到端：合成账号断言浏览器发送、服务端入库、聚合与显示一致（M3）

## FIX-2a｜史料硬伤与出处质量（F4，门禁按 M5 升级）

- `industrial_revolution.html:1107–1108`：删除"世界上第一部"断言，改为"英国最早的工厂立法之一；1802 年《学徒健康与道德法》已先行限制学徒工时"
- 史料分级标注：`primary / secondary / reconstruction / fiction / unverified`；要求原始记录定位、原文或可核验摘录、翻译说明、编者处理、许可、争议与审校记录
- `source:{}` 或单条随意 URL 不得通过校验；`scripts/validate-content.mjs` 按分级规则校验
- 未核材料不得作为事实判定依据；五剧本未核材料不得批量冒充史料

## FIX-2b｜证据阅读任务（F2）

保留错答继续的失败可恢复设计；补可选提示与有意义的证据比较任务；不引入硬卡关。

## FIX-3｜结局统计（F5，粒度按 M4 重写）

- 废止 `(actorId, scriptId, phase)` 去重（会吞掉重玩与多结局证据）
- 引入独立 `attemptId` 贯穿剧情与测验；事件传输重试以事件 ID 幂等
- 同一 attempt 同一阶段只计一次；`unique actor`、`unique session` 另行定义
- 新协议固定为 `script.ending` 仅记录故事完成，`quiz.complete` 记录测验完成；二者以 attemptId 关联。禁止阶段行相加当完成次数。完整字段与旧数据兼容见 ENG-13
- 历史数据无法恢复 attempt 的，保留为未知，不伪造
- 测试覆盖：退出续玩、同剧本两次完整游玩、多个结局、重复网络发送、旧客户端

## FIX-4｜资产校验门禁（调整后）

- **404 报告**（P0）：扫描配置 `dir` + `defaultExpr`/`file` + `ext` 动态拼接，覆盖大小写与路径变体；最终以真实浏览器网络请求复核，静态扫描不作为唯一依据
- **死资产报告**（仅候选清单）：双口径扫描输出，**不依据静态扫描直接删除**；删除须权属登记与回滚方案确认后单独执行（暂缓，见第五节）
- **同字节检测**：md5 相同图片超过 2 份告警
- **资产权属登记**（新增，M10）：第三方名称、图片、音乐及衍生资产分别记录来源、许可证、允许用途、权利人、替换状态；权属不清的隔离或替换。删除 alt 文案中的第三方名称只改善展示，不视为获得版权

# 四、C 实验（S2–S4 批次，按 M7/M9 修订）

## 4.1 单元设计

- **核心问题**：帮助汤姆验证工厂是否执行法规；允许证据不足、继续调查、修正结论
- **史料**：英国议会 1833 工厂法页面与国家档案馆教学档案；**档案馆检查员报告含 1863 年记录，不得当作 1833 年即时状况**；原件、译文与具体年份须教师审校
- **机制**：优先复用汤姆、证物调查、回响及现有信任机制；信任仅影响叙事或可选线索，核心史料始终可获取。独立测验不提供 NPC 协助。纸面原型无需联网；数字原型先用规则反馈，若现有引擎无法表达任务，记录最小差距并独立审批
- **反馈**：后续反馈显示判断影响了什么，历史事实与虚构后果分栏呈现

## 4.2 交付物

史料卡（分级标注＋审校记录）、任务流程图、两套同目标独立题、机制映射表、**纸面原型（仅用于形成性研究）**。

## 4.3 验证方案（E0–E2，按 M7/M9 修订）

- **E0**：版本一致性、FIX-1 独立测试、合成事件端到端断言、隐私审批（M11）
- **E1 形成性**：6–10 名学生，仅用于发现摩擦与修正流程，**不用于群体效果裁决**；纸面原型可用
- **E2 正式比较**：**同媒介**（同数字媒介、历史目标、史料、角色、时限、奖励与视听资源；允许被检验的探究机制有意不同）比较 B0（泄漏修复后基线）/ C1（数字版史料探究）；教师阅读组 T 为教育效果参照，不强行要求相同游戏内行为指标
- **预注册**：目标年龄（现有教学元数据主要九年级，首位试用者高一）、招募范围、随机单位、组间串扰、等值题、缺失处理、最小重要差异、样本量依据、停止规则、评分员一致性（加权 kappa 或 ICC）
- **报告**：按分配组报告而非仅完成者；报告不确定性、负例与异质性；一次工业革命试验不决定全部五剧本或原创世界的商业战略

## 4.4 排队实例

传单短章（法国大革命）：核心史料须精确到日期、地点、单位及出处（1789 年 1 月巴黎面包 8→14 苏等）；C 实验证据出来前不投入制作。
