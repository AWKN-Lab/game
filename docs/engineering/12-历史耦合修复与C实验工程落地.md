# 二、P0 修复（立即执行，既有方向内授权）

## FIX-1｜答案位置泄漏（F1）

**方案**：数据层改用稳定 `optionId`；渲染层按会话级随机种子打乱展示顺序；判定、反馈、埋点全部改用 `optionId`，与展示顺序解耦。

改动范围：

- `engine.js` `showEvidence()` / `selectEvidenceOption()`：渲染前 shuffle（Fisher-Yates，种子 = 会话 ID + 题目 ID，保证同会话重开存档顺序稳定）；`quiz.answer` 埋点增加 `optionId`、`displayIndex`、`correctIndex` 三字段
- 五剧本 evidence 块：为每个选项补 `optionId`（如 `ev-ir-3-opt-a`）
- 兼容：旧存档无 optionId 时按原索引回退

**测试**（新增，进 `tests/`）：

1. 多随机种子下判定一致性：同一作答 optionId 在任意展示顺序下判定相同
2. 正确项分布统计：100 个种子中正确项出现在各位置的比例无显著偏斜
3. 旧存档回退路径
4. 可访问性：键盘导航与读屏顺序跟随展示顺序

## FIX-2｜史料硬伤与出处标注（F4）

- `industrial_revolution.html:1107–1108`：删除"世界上第一部"绝对断言，改为"英国最早的工厂立法之一；1802 年《学徒健康与道德法》已先行限制学徒工时"

# 四、C 实验：工业革命史料探究原型

## 4.1 单元设计

- **位置**：工业革命剧本第三至五幕，10–15 分钟单元
- **核心问题**：仅有法律条文，能否确认工厂实际合规？
- **史料**：英国国家档案馆 1833 工厂法教学档案（检查员报告、违规记录）。**原件页面此前访问受限（403），原件复核是制作门禁，未复核不得进入原型**
- **机制复用**：汤姆（NPC）、证物调查、信任门槛、回响；不扩建引擎
- **流程**：任务开场 → 自主选择查规则/检查记录/问 NPC（首次提供来源、时间、身份、易读翻译）→ 用两个证据 ID + 一句可选理由支持判断 → 选择下一步调查（各方案信息收益与局限不同）→ 汤姆回响引用玩家先前选择提出新疑问 → 外部测验：解释一份未见过的材料支持或反驳什么
- **分栏呈现**：历史事件实际发展与玩家虚构行动后果分开，注明虚构

## 4.2 交付物

1. 教师确认的史料卡（archive_id、标题、年代、作者、出处链接、原文、译文、删节、证据局限、审校者、权利状态）
2. 任务流程图
3. 两套同目标独立题（防题目记忆效应）
4. 现有机制映射表
5. 静态/纸面原型（暂不接 AI 服务，自由理由评估由教师或盲评者完成）

## 4.3 验证方案（E0–E2）

- **E0 上线基线核验**：确认试用版本与提交一致；FIX-1 独立测试通过；合成账号复跑埋点；隐私审批（自由输入运行态存储单独评估）
- **E1 形成性观察**：约 6–10 名目标年龄学生，覆盖不同历史基础与阅读能力；观察卡点与主动探索时刻；事后开放访谈，保留负面反馈
- **E2 比较实验**：随机分配 B0（修复泄漏后现有单元）/ C1（史料探究原型）/ T（同史料教师引导阅读讨论）；固定美术、叙事长度、角色、史料、奖励与音频
- **测量**：乐趣（无奖励自愿续玩、7 日回访）、历史知识（前测/后测/7 日延迟）、历史推理（新史料任务，五维 0/1/2 盲评：来源辨析、时空定位、证据互证、因果解释、虚构辨识；双人加权 kappa 或 ICC）
- **预注册决策门槛**：实验启动前由教师、产品方与独立测量人员预注册最小有意义学习增益、可接受体验差异、关键错误上限与停止条件。探索性样本只报原始计数与不确定区间，不宣称显著胜利

## 4.4 排队的第二实例

传单短章（法国大革命）：印刷学徒查证传单真伪。核心史料：1789 年 1 月巴黎四磅面包 8→14 苏；"饥荒阴谋"谣言（largely imagined，恰为教学核心）；pacte de famine；小册子时代。史实红线：不采用"单一商人囤积"叙事。C 实验证据出来前不投入制作。
