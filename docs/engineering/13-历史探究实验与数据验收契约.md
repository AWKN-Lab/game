# ENG-13｜历史探究实验与数据验收契约

> 版本：V0.1，2026-11-28；设计提案，待独立复核。
> 基线：main 500ff814ac4e8768c5fcb0825ab22f5d5f293c2e；代码与 CI 证据基线 a0616e6（65 项通过、33 类事件）。
> 范围：补齐 PRD V2.1、ENG-12 V1.2、ENG-10 V1.1 的操作契约。未经审批不改变运行时、生产、真实儿童数据或部署。本文新增字段、阈值与实验均未实装或实测。

## 1. 目标、因果机制与反证

产品目标同时满足：孩子获得真实历史理解与主动参与乐趣；家长接受安全、时间与价值；学校接受课程效度和实施成本。史实、安全、隐私、可访问性为硬门禁；学习与乐趣为分别达标的双目标。允许错误选择、失败、回访证据、重新判断；历史结局与学习认证分开。

每个探究单元必须提交结构化设计表：unitId、contentVersion、学习目标、历史时空、事实命题及来源、虚构标记、玩家目标、候选行动、所需历史信息、可见反馈、证据不足时的行动、独立评估、可能捷径与反例。先复用已有 NPC、证物、回响、卡牌；只为明确缺口申请最小工程变化。

反事实不是通关锁：
- R1 保留历史信息，改变呈现渠道，比较决策与独立解释；若保持，支持渠道可替换。
- R2 保留操作与反馈，移除关键历史信息；控制既有知识、选项长度和语气等线索，比较决策质量及迁移，允许继续游玩。
- R3 在明确标示的假设情境中改变一项相关约束；预先列应变化与不应变化的判断。不改真实史实记录。若效果不足，检查操纵、先验知识、测量灵敏度、样本不确定性与机制假设。
- 反例：强制点卡、猜第三项、刷属性或让 NPC 给答案即可高分；已具备知识者直接解释并通过；无设备者不能回访。不得将这些行为等同于历史学习失败或成功。

预期：历史信息增加应提高合理判断与迁移，并至少维持可接受乐趣。实际结果可能推翻假设。单个单元的成功不能外推全部题材。

## 2. 运行身份与事件契约

### 2.1 身份与状态

actorId 为既有匿名身份；sessionId 为浏览器会话；attemptId 为每次独立游玩实例的随机 UUID（禁止从个人信息生成）。scriptId 和 contentVersion 在 attempt 创建时绑定并持久化；采用稳定 questionId 与 optionId，正确性依据 correctOptionId。

状态：NEW → ACTIVE → STORY_COMPLETE → QUIZ_COMPLETE。退出只是暂停；续玩恢复同 attempt；重开剧情显式建立新 attempt。故事完成后可延迟测验；测验缺席保留 STORY_COMPLETE。重复回调不得重发阶段语义。若同一 attempt 同阶段出现不同结局或版本，标记冲突并从正式统计隔离，禁止静默覆盖。多标签同 attempt 需并发锁或独立 attempt；实现前选定一种并测试。内容版本改变时优先保留原内容；不兼容时明确重启或记录迁移映射，禁止猜测。旧存档无法映射时保留原记录并提示重新进入相关节点。

随机化使用持久化 attemptId + questionId + contentVersion 派生稳定种子，固定 Fisher–Yates 实现和算法版本；只乱序显示，不改变答案、反馈与属性效果。测试固定 300 个预先登记种子，每位置比例建议落在 25%–42%（三选项；其他选项数另定），覆盖所有位置；此范围是工程候选验收线，非统计证明。另做全排列正确性、续玩一致、旧存档、键盘和真实读屏验证。

### 2.2 新版事件（拟议，沿用既有名称）

| 事件 | 新版 payload 必需字段 | 语义 |
|---|---|---|
| script.start | attemptId, scriptId, contentVersion, mode | 独立 attempt 开始；恢复不计第二次开始 |
| script.act_enter | attemptId, scriptId, contentVersion, actId | 幕级观察，允许再次进入 |
| script.choice | attemptId, scriptId, contentVersion, nodeId, choiceIndex, actId, timed | 选择诊断；沿用既有 choiceText 白名单时仅允许固定选项文字 |
| script.evidence_open | attemptId, scriptId, contentVersion, nodeId, evidenceId | 面板打开，非阅读证明 |
| quiz.answer | attemptId, scriptId, contentVersion, questionId, optionId, correct | 首次作答；可选 displayIndex 诊断。旧 choiceIndex/knowledgeId 兼容读取 |
| script.ending | attemptId, scriptId, contentVersion, endingType | 仅故事完成，取消测验后第二次发出；legacy learningTier 保留解析 |
| quiz.complete | attemptId, scriptId, contentVersion, score, total, pct, learningTier | 测验完成，与故事完成独立 |

传输 eventId 保持现有唯一幂等，重试复用原 eventId；分析语义键为 (attemptId, name)，仅用于 start/ending/quiz.complete；幕次按 attemptId+actId 漏斗去重，答题首次按 attemptId+questionId。事件迟到不等于新尝试。若同 attempt 的 actor/script/version 关联冲突，隔离并报告。无新增 ID 的旧事件仍可存入原表，分层 legacy；服务端拒绝恶意类型、越权/超长字段，不从旧 session 推造 attempt。字段白名单必须同时更新 assets/js/event-client.js、data/event_catalog.json、server/app.js、scripts/validate-events.mjs、API/DB/看板与文档。具体迁移实现由工程负责人设计并提交复核，原始事件不删除；可通过兼容视图或索引实现聚合，避免未经评审的结构迁移。

### 2.3 端到端负例

合成账号：开始→答题→暂停→新会话恢复→故事结束→重复网络提交→完成测验→次日重开→另一结局。期望 2 个 attempt、2 个故事完成、按实际测验次数计数；重复请求不增加计数；不同版本不合并。旧客户端无 attempt 字段仍能使用，后台显示 legacy；缺失、伪造、冲突字段不能污染新版统计。核对浏览器请求、服务端存储、查询与界面四层，记录版本及测试输出。现有 33 类事件数不作为新协议成功指标。

## 3. 史料和 C 原型契约

史料卡 schema：sourceId、type(primary/secondary/reconstruction/fiction/unverified)、title、author 或 unknownReason、documentDate、period、place、archive/collection、locator、url、originalExcerpt 或可查原文定位、translation、editorialNotes、rightsStatus、limitations、reviewerRole、reviewedAt、reviewStatus。primary/secondary 的可引用事实须 reviewed 且来源定位、日期、引文、译文、许可齐备；reconstruction 标注重建依据与不确定性；fiction 明示虚构；unverified 禁止作为判对、因果反馈和独立测验的事实依据。静态 validator 检查结构及引用，教师/历史审校者验证真实性、上下文和翻译，不能由 URL 存在自动通过。每个事实命题有 sourceId 引用；无权使用的资产隔离。现存素材未审校时维持待核状态，不宣称全库通过。

### 3.1 最小任务：工厂检查

历史背景：1833 年英国工厂立法及后续执行。候选出处：[英国议会早期工厂立法](https://www.parliament.uk/about/living-heritage/transformingsociety/livinglearning/19thcentury/overview/earlyfactorylegislation/)、[1833 工厂法](https://www.parliament.uk/about/living-heritage/transformingsociety/livinglearning/19thcentury/overview/factoryact/)、[英国国家档案馆教学档案](https://www.nationalarchives.gov.uk/education/resources/1833-factory-act/)。具体原件、记录时间、适用行业、年龄、工时及翻译待审校；1863 年记录不得当作 1833 年的同时证据。若目标史料不可访问，选择可核原始档案替代并重新审校，不凭二手概述生成原件。

设计：汤姆请求玩家核查工厂是否遵守当时适用规则。玩家自行选取法条、检查记录与角色线索；记录证据出处和局限，作出“支持合规／支持违规／证据不足”的暂定判断，再决定查哪份证据或如何提出合理要求。每条行动产生可感知的信息或关系反馈；证据不足有继续调查路径。历史事实与模拟行动后果分栏。角色信任可改变表达与可选线索；必需证据不依赖联网、好感、付费或速度。NPC 使用审校后的规则提示，不能直接公布任务答案；独立评估不提供提示。纸面原型先验证任务目标、阅读难度及可见后果；数字原型复用同一任务，缺少必要表达时单独申报最小改动。

验收反例：只点击全部卡片、选择唯一长选项、重复猜测、刷信任或直接复制 NPC 回答不能被评定为历史理解。允许证据充分的不同解释、证据不足与合理修正。教师须审查任务是否符合目标年龄的历史课标及语言负荷。

## 4. 试用、评估与决策

E0 合成账号技术核查；E1 约 6–10 人发现摩擦，不做效果定论；E2 经预注册后才开展。先确定目标年龄、场景、历史先验知识及是否同意参与。B0/C1 使用同一数字媒介、审校史料、目标、角色、视听与时限，唯一主要差异为探究机制及其必要反馈；T 为相同历史目标的教师阅读参照，不比较游戏内行为。分配单位、班级串扰、样本量、最小重要差异、失访规则、停止条件、分析代码在看结果前签字锁定。形成性反馈不可替代正式比较；若无法同媒介，只报告可用性观察。

历史理解分别评估：基础事实前后测、7 日延迟保持、未见过的同类史料迁移。题目 A/B 平行且经教师审查；独立评估不提供 AI 或原题提示。迁移五维每维 0/1/2：来源辨析、时空定位、证据互证、因果解释、史实/虚构辨识。0=缺失或明显错误，1=部分正确或理由不足，2=正确且引用相关证据并识别局限；正式评分须为每题准备具体例答、边界例与错误例，由双人盲评、先独立评分再仲裁，报告加权 kappa 或 ICC、实际分歧。总分合格线由教师和测量人员预注册，不事后追认。

自主机会：研究方提供同等可选时间、设备和入口；允许离开、选择其他活动。观察主动选择、无额外激励续玩、7 日自主回访，分别记录机会覆盖、家长/学校限制及缺测。按分配组报告学习与机会；仅在机会定义满足者报告条件参与率，同时报告全组覆盖，避免选择偏差。家长再次支持、安全与时间接受度；教师课程适配、备课时长、课堂可行性、再用意愿分别记录。禁止把使用时长、NPC 轮数、积分或答题分数作为单独成功证据。

决策矩阵（数值门槛须预注册）：
| 学习增益 | 自主乐趣 | 决策 |
|---|---|---|
| 达标 | 达标 | 可申请下一相近历史单元试验，仍需安全与三方采用门禁 |
| 达标 | 未达标 | 改任务目标、节奏、阅读与反馈，保留学习机制候选 |
| 未达标 | 达标 | 优先修复历史推理耦合；不扩大内容投入 |
| 未达标 | 未达标 | 暂停方案，重新提出竞争性机制假设 |
| 证据不足 | 任意 | 明确缺口与下一次最小验证；不宣称获胜 |

硬约束失败立即停止相关试用，处理风险后另行审批；不能用乐趣或学习收益抵消。A/B、IP 和完整世界建设独立立项，需各自学习目标、内容效度、需求和实测成本；一次 C 结果仅适用于相近人群与单元。

## 5. 隐私、安全与权属

E0 使用合成数据；真实儿童研究前由实际责任人签收适用的家长授权、儿童同意、学校审批、数据清单、访问权限、保留期与删除演练（含备份到期）、退出方式、供应商处理与适用地区要求。研究编号与联系人分离；仅采集必要的结构化事件、评分和观察，不采集无关身份或持续录屏。实验优先关闭自由输入及长期记忆，必须使用时另审运行态存储、归档、删除、泄露与模型数据流。匿名标识不等于无法关联个人。规则提示优先，不将未经核实的模型输出作为史实。权属登记覆盖图片、音频、名称及衍生资产；删文案不能取得授权。确认侵权风险须隔离/替换，死资产仅输出候选，删除需单独批准与回滚。
