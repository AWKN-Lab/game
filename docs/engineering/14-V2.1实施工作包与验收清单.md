### 5.2 权威事件路径

engine.js:ttHook 注入 attemptId/scriptId/contentVersion；新 attempt 才发 script.start，续玩不重发；故事结束只发 script.ending；showQuizResult 只发 quiz.complete。阶段与待发记录状态一致，防止先标已发实际未入队。使用持久化 eventId 幂等；拒绝采集期间不生成待发记录，重新授权不追传。

game-hooks.js 与 shell-runtime.js：iframe 只由已登记同源父页上传；校验 origin、event.source 和 scriptId，hooksActive 按 frame/load 管理，DOM 兜底仅 legacy。直开五剧本当前未见 identity/event client 直接引入，实施时核实依赖并补公共入口和 consent。禁止子父页同时上传。shell-runtime.js:187 旧加载 start 在新版正式桥接时取消。validate-events 加正式 start 覆盖。测试 iframe 首载/重载、直开、重玩、旧壳、未知消息来源、授权关闭。

### 5.3 队列风险

- 按 eventId 从最新队列删除服务端确认项，避免旧快照覆盖在请求期间新增记录；
