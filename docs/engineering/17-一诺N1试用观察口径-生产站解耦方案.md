## 3. 观察口径（人工观察替代埋点）

### 3.1 看什么（按 ENG-14 铁律「好玩的前提是学到历史」）

| 维度 | 观察点 | 记录方式 |
|---|---|---|
| 可用性 | 能否独立开始并推进一幕？卡在哪一步？ | 陪同者记录卡点时刻 |
| 通关/时长 | 每幕用时、是否主动放弃、放弃点 | 计时+放弃页截图 |
| 证据题表现 | 答错率、错后行为（重试/跳过/烦躁） | 逐题勾记 |
| 自主探索 | 是否主动点非必选项、回看证据、试不同选择 | 人工判读（无 initiator 字段，按 ENG-16 E3 口径人工标注「自主/剧情强制」） |
| 乐趣信号 | 主动重玩、笑、追问"还有吗"、主动换剧本 | 直接引述原话 |
| 学习信号 | 玩后能否复述 1 个历史事实（如辛亥幕的关键抉择） | 玩后 2 分钟问答 |

### 3.2 N=1 能回答 / 不能回答

**能回答**：可用性硬伤（能不能玩下去）、明显卡点、好玩初判、剧情文本是否超龄或过幼。
**不能回答**：北极星率（无埋点）、学习效果的因果判断、任何统计意义的结论。**N=1 数据不进 P0 判定基线**，只做方向性输入。

### 3.3 数据污染说明（hint 候选 3 收口）

位置泄漏（correctIndex 全=2）自上线即存在，但生产站**无埋点上报**，历史会话未产生服务端数据，**污染范围=零**（localStorage 存档仅在一诺设备上，不含判分记录）。D1 随机化上线后无需清洗历史数据，基线从零开始采集——D1 紧迫性据此校准：不污染历史，但影响未来 P0 数据，签收后随 W03–W05 落地即可。
