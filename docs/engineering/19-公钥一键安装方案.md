# ENG-19 公钥一键安装方案（降摩擦版）

> 背景：部署唯一卡点=lingguang-agent 公钥未装（14:12 复测 161/29 均 AUTH_DENIED，出口 IP 47.102.180.69 在放行网段内，连接可达 sshd）。
> 本方案把「装公钥」从多步操作降为**粘贴一条命令**。

## 一键命令（在 8.134.179.161 服务器终端粘贴执行一次即可）

```bash
mkdir -p /home/lingguang-agent/.ssh && echo 'ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAIF+6zsUWjPDIQoL/kr+g7r1pj+gnFKQpRPnJGYxXLC/f lingguang-agent' >> /home/lingguang-agent/.ssh/authorized_keys && chmod 700 /home/lingguang-agent/.ssh && chmod 600 /home/lingguang-agent/.ssh/authorized_keys && echo 公钥已装好
```

- 幂等：重复执行无副作用（append + 权限修正）。
- 执行入口（任选其一）：宝塔面板「终端」、阿里云控制台「云助手/发送命令」、或任何能登服务器的现有方式。
- 执行完回一句「装了」，灵光 1 分钟内自动复测并开始部署（deploy.sh 现成，releases+软链+verify 全自动，回滚脚本同在）。
