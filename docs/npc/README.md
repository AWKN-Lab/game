# 一、两层 NPC 设计（不变）

1. **原创见证者**（本目录发卡）：每剧本一名，自由对话主要对象，视角是"亲历的小人物"。
2. **史实型证言 NPC**（不发卡）：历史人物只做证言型对话，严格锚定剧本知识库，不虚构内心独白，不设信任状态。
3. **全局引导者**：子衿、洛书跨剧本复用，记忆按剧本隔离。

---

# 二、V2.0 完整 OC 的九件套

V1.0 骨架卡经自评不完整（缺创伤、世界观、关系网、视觉锚点、成长弧线）。V2.0 每张角色卡补齐：

| 件 | 内容 | 回答的问题 |
|---|---|---|
| 1 | 反差内核（面具 vs 执念） | 他装成谁 |
| 2 | **形成事件（创伤）** | 执念从哪来 |
| 3 | **欲望-恐惧冲突** | 他想要什么、怕什么、行为怎么摇摆 |
| 4 | 语言指纹 + 识别钩子 | 怎么听出是他 |
| 5 | **潜台词对照表** | 嘴上说的 / 心里想的 / 实际做的 |
| 6 | **误解方式清单** | 他会怎么错——不是"不知道什么"，而是"怎么错" |
| 7 | **视觉锚点** | 长相、衣着、随身物件、习惯动作 |
| 8 | **成长弧线** | 开局 → 中点 → 收局 |
| 9 | 信任触发 + 正反示例 + 回响锚点 | 怎么相处、怎么被记住 |

# 三、世界观卡（每剧本一张）

角色卡再好，没有世界卡就是舞台上的独角戏。每张世界观卡五件事：

1. **钱与物价**：关键数字锚点（工资、物价、盘缠）；
2. **权力结构**：谁管谁、怕什么官、越界的代价；
3. **日常质感**：吃、住、行、干活；
4. **消息传播**：消息怎么走、多快、多可靠；
5. **守恒账本**：供 NPC-2 门禁与四联对账（ENG-09 4.6）使用的数字与事实锚点。

> 守恒账本中的数字为**剧本内锚点**，供生成对账使用；与史实有出入时以剧本知识库修订为准，不得由 AI 外推。

# 五、使用规则（不变，补一条）

1. 本目录为**唯一事实源**：提示词组装、修改、纠正一律先回卡再生效；
2. 入库按 ENG-09 第 5 节数据模型，`persona_json` 与本目录一致；世界观卡数字进守恒账本，供四联对账调用；
3. 回响锚点按 `PLANTED → RIPENING → HARVESTED` 管理；
4. 修改须走剧本审核流程，AI 不生成、不修改人设卡与世界观卡；
5. **跨卡对账**：任何角色卡的修改须检查关系网（30）与所属世界观卡是否需要同步更新。
