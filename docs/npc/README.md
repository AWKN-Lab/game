# 一、两层 NPC 设计

本产品 NPC 分两层，OC 卡只覆盖第一层：

## 1. 原创见证者（本目录发卡的 OC）

每个剧本一名原创角色，是学生自由输入对话（MOD-AI-04）的**主要对象**：

- 身份、性格、经历均为原创，不背负史实评价负担，可以放心自由对话；
- 视角是"亲历的小人物"，能说细节、说情绪，补史实人物不能编的部分；
- 卡片按 ENG-09 骨架卡规范：反差内核、识别钩子、语言指纹、信息雾边界、信任触发规则、正反示例。

## 2. 史实型证言 NPC（不发 OC 卡）

剧本中的历史人物（孙中山、谭嗣同、华盛顿、罗伯斯庇尔等）：

- 只做**证言型对话**：台词严格锚定剧本知识库与史实记录，不虚构内心独白、不编造未记载的言论；
- 自由输入一律先过历史审稿人（MOD-AI-06），`anachronism` / `factual_error` 由角色以困惑或纠正回应；
- 不设信任状态、不做性格演绎——历史人物的性格演绎本身就是一种"编造"，风险大于收益；
- 若学生想深聊，引导至本剧本的原创见证者（"这些事你去问 XX，他在场"）。

## 3. 全局引导者

子衿（历史引导者）与洛书（道法追问者）跨剧本复用，记忆按剧本隔离（ENG-09 4.1），人设跨剧本稳定。

# 三、使用规则

1. 本目录卡片为**唯一事实源**（IP 技能"人物圣经"纪律）：提示词组装、修改、纠正一律先回卡再生效；
2. 卡片进入 `npc_persona` 表时按 ENG-09 5 节数据模型落库，`persona_json` 与本目录内容一致；
3. 每张卡的"回响锚点建议"是剧本元数据登记回响锚点的输入，生命周期按 `PLANTED → RIPENING → HARVESTED` 管理；
4. 修改卡片须走剧本审核流程（历史审稿人可辅助校对知识边界），AI 不生成、不修改人设卡。
