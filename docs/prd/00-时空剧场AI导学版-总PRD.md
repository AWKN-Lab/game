# 一、结论先行

本次升级保留五个现有剧本、互动剧情引擎、卡牌、知识测试和学习记录。

产品新增三条闭环：

1. **教师导学闭环**：老师输入课堂条件，AI 从现有剧本和知识点中整理课堂目标、建议剧情、暂停提问、板书和课后任务。
2. **学生复盘闭环**：系统读取学生的真实进度、错题和评级，AI 输出掌握内容、混淆点、错因和复习动作。
3. **用户反馈闭环**：系统记录经过定义的产品互动，用户可以提交反馈和愿望，管理员据此处理问题并安排后续剧本与功能。

学生和教师继续免注册使用核心能力。

管理员需要安全登录，才能查看匿名互动数据、用户选择、反馈和许愿池。

本期不建设全班共演、班级管理和实时投票。

# 二、产品目标

## 2.1 用户目标

### 教师

在两分钟内得到一张可以直接使用的导学卡，减少重新整理长教案的时间。

### 学生

在完成剧本后得到一张具体复盘卡，知道自己错在哪里、下一步做什么。

### 普通用户

遇到问题时可以在当前上下文直接反馈，也可以告诉产品团队最想优先开发的剧本和功能。

### 管理员

能够：

- 查看定义范围内的用户互动；
- 查看用户在剧本中的选择、答题和完成路径；
- 查看并处理用户反馈；
- 审核、合并和排期许愿池需求；
- 维护剧本元数据、知识点、AI 提示词和本地降级规则；
- 查看管理员操作审计。

## 2.2 业务目标

- 展示现有五部互动历史剧本的内容资产；
- 展示真实 AI 调用；
- 完成课前到课后的最小学习闭环；
- 建立用户需求进入产品路线图的反馈闭环；
- 用真实互动数据替代主观猜测；
- 证明普通电脑或手机可以使用；
- 控制课堂侧复杂度，确保比赛前完成。

## 2.3 成功指标

| 指标 | MVP 验收值 |
|---|---|
| 导学卡生成成功率 | ≥ 95%，含规则降级 |
| 导学卡生成时间 | 正常网络下 ≤ 20 秒 |
| 导学卡长度 | 一屏到一页 |
| 复盘卡使用真实数据 | 100% |
| 五个现有剧本回归 | 核心流程全部可运行 |
| AI 失败可用性 | 自动返回规则版 |
| 学生使用门槛 | 无需注册 |
| 核心事件采集成功率 | ≥ 98%，允许离线队列重试 |
| 用户选择可追踪率 | 关键选择节点 100% |
| 反馈上下文完整率 | ≥ 95% 自动带剧本、页面或节点 |
| 许愿处理率 | 管理员可完成审核、合并、回复和状态更新 |
| 管理后台访问控制 | 未授权用户 100% 无法访问 |

# 五、核心用户流程

## 5.1 教师流程

```text
进入剧本详情
→ 点击生成 AI 导学卡
→ 选择课堂时长
→ 选择学生基础
→ 输入教学重点
→ 选择投屏或学生自学
→ 生成导学卡
→ 使用剧本教学
```

异常流程：

```text
AI 超时或失败
→ 自动使用本地规则
→ 正常展示导学卡
→ 标记“规则版”
```

## 5.2 学生流程

```text
游客进入
→ 选择剧本
→ 完成剧情互动
→ 完成知识测试
→ 点击生成学习复盘
→ 查看掌握、混淆、错因和下一步
```

无有效学习数据时：

```text
点击复盘
→ 提示先完成知识测试
→ 提供返回剧本按钮
```

## 5.3 用户反馈流程

```text
在当前页面点击反馈
→ 选择反馈类型
→ 填写问题
→ 系统自动附带剧本、幕次、节点和页面
→ 提交
→ 用户获得反馈编号
→ 管理员处理并更新状态
```

## 5.4 许愿池流程

```text
进入许愿池
→ 选择剧本愿望 / 功能愿望 / 问题愿望
→ 填写标题和原因
→ 选择是否同意公开
→ 提交
→ 管理员审核
→ 合并重复愿望
→ 公开状态
→ 调研 / 计划 / 开发 / 已实现
```

## 5.5 管理员流程

```text
安全登录
→ 查看总览
→ 筛选日期、剧本、事件或匿名用户
→ 查看用户完整互动时间线
→ 查看选择、答题、反馈和愿望
→ 处理反馈
→ 审核和合并愿望
→ 设置产品回复、优先级、负责人和计划版本
→ 发布状态更新
```

管理员还可以继续：

```text
维护剧本注册表
→ 维护知识点
→ 维护教学元数据
→ 维护 AI 提示词
→ 维护规则降级模板
→ 发布并回归验证
```

# 七、数据原则

1. 学生和教师默认使用匿名 ID；
2. 本机 `localStorage` 继续负责学习续玩；
3. 云端事件系统只接收事件目录中的白名单字段；
4. 不宣称学生学习数据云同步；
5. 管理员是本期唯一需要正式服务端登录的角色；
6. 不上传密码、密码哈希和浏览器完整存储；
7. 自由文本只在用户主动提交反馈、愿望或 AI 输入时保存；
8. AI 请求只发送完成导学或复盘所需字段；
9. 所有 AI 输出保留来源字段和生成模式：`ai`、`rule` 或 `failed`；
10. 历史事实必须来自剧本内容系统；
11. 事件采集失败不得阻断剧情；
12. 管理员查看、修改和导出数据必须写入审计日志；
13. 不建立广告画像和未成年人商业画像；
14. 用户可以关闭数据改进计划并清除本机数据。

# 十一、非功能要求

## 稳定

- AI 超时不阻断页面；
- 五个原剧本不依赖 AI 才能运行；
- 新功能异常不污染原有学习数据；
- 事件上报失败进入本机队列；
- 事件重试必须幂等。

## 性能

- 表单提交后立即显示加载状态；
- AI 请求超时建议 15 秒；
- 超时后直接转规则版；
- 事件批量上报，不在每次点击阻塞页面；
- 管理员常用列表首屏建议 3 秒内完成。

## 内容

- AI 输出一页以内；
- 使用具体知识点；
- 不使用空泛鼓励；
- 不给学生贴标签；
- 不新增未核验史实；
- 用户提交文本公开前必须审核。

## 安全

- 管理员服务端登录；
- 管理接口权限校验；
- 密码不存前端；
- 登录和敏感操作限流；
- 管理员操作审计；
- 自由文本防注入和转义；
- 导出操作二次确认。

## 隐私

- 默认匿名；
- 最小字段采集；
- 用户知情；
- 支持关闭数据改进计划；
- 不采集屏幕录像和键盘输入；
- 不建立商业广告画像。

## 兼容

- 桌面浏览器；
- 手机浏览器；
- 普通投影环境；
- AI 不可用时的本地模式；
- 事件服务不可用时的离线队列。

# 十三、总验收

1. 老师可以从任一剧本详情页生成导学卡；
2. 导学卡包含目标、剧情、提问、板书和任务；
3. 学生完成测试后可以生成复盘卡；
4. 复盘卡使用真实错题和评级；
5. AI 失败时两类卡片仍可生成；
6. 五个原有剧本核心流程正常；
7. 页面删除不存在的云同步表述；
8. 第三方角色 IP 已完成替换或隔离；
9. 全新环境可以按 README 构建运行；
10. 管理员可以查看定义范围内的用户互动、选择和反馈；
11. 管理员可以按匿名用户查看完整事件时间线；
12. 用户可以提交希望优先开发的剧本和功能；
13. 管理员可以审核、合并、回复、排期和更新愿望状态；
14. 未授权用户无法访问管理员页面和接口；
15. 事件采集失败不影响剧情和学习；
16. 系统不采集密码、屏幕录像和无关私人信息。
