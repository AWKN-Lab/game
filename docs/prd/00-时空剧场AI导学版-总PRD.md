# 一、结论先行

本次升级保留五个现有剧本、互动剧情引擎、卡牌、知识测试和学习记录。

新增两项能力：

1. **教师导学卡**：老师输入课堂条件，AI 从现有剧本和知识点中整理出课堂目标、建议剧情、暂停提问、板书和课后任务。
2. **学生学习复盘卡**：系统读取学生的真实进度、错题和评级，AI 输出掌握内容、混淆点、错因和复习动作。

产品不建设全班共演，不建设班级管理，不要求学生注册。开发增量集中，演示闭环清楚。

# 二、产品目标

## 2.1 用户目标

### 教师

在两分钟内得到一张可以直接使用的导学卡，减少重新整理长教案的时间。

### 学生

在完成剧本后得到一张具体复盘卡，知道自己错在哪里、下一步做什么。

### 管理员

能够维护剧本元数据、知识点、AI 提示词和本地降级规则，保证内容稳定。

## 2.2 业务目标

- 展示现有五部互动历史剧本的内容资产；
- 展示真实 AI 调用；
- 完成课前到课后的最小闭环；
- 证明普通电脑或手机可以使用；
- 控制开发范围，确保比赛前完成。

## 2.3 成功指标

| 指标 | MVP 验收值 |
|---|---|
| 导学卡生成成功率 | ≥ 95%，含规则降级 |
| 导学卡生成时间 | 正常网络下 ≤ 20 秒 |
| 导学卡长度 | 一屏到一页 |
| 复盘卡使用真实数据 | 100% |
| 五个现有剧本回归 | 核心流程全部可运行 |
| AI 失败可用性 | 自动返回规则版 |
| 学生使用门槛 | 无需注册 |

# 五、核心用户流程

## 5.1 教师流程

```text
进入剧本详情
→ 点击生成 AI 导学卡
→ 选择课堂时长
→ 选择学生基础
→ 输入教学重点
→ 选择投屏或学生自学
→ 生成导学卡
→ 使用剧本教学
```

异常流程：

```text
AI 超时或失败
→ 自动使用本地规则
→ 正常展示导学卡
→ 标记“规则版”
```

## 5.2 学生流程

```text
游客进入
→ 选择剧本
→ 完成剧情互动
→ 完成知识测试
→ 点击生成学习复盘
→ 查看掌握、混淆、错因和下一步
```

无有效学习数据时：

```text
点击复盘
→ 提示先完成知识测试
→ 提供返回剧本按钮
```

## 5.3 管理员流程

MVP 通过配置文件完成：

```text
维护剧本注册表
→ 维护知识点
→ 维护教学元数据
→ 维护 AI 提示词
→ 维护规则降级模板
→ 发布并回归验证
```

# 七、数据原则

1. MVP 使用本机 `localStorage` 保存学生学习数据；
2. 不宣称云同步；
3. 学生无需提交真实姓名；
4. AI 请求只发送完成导学或复盘所需字段；
5. 密码和伪登录能力在 MVP 中不作为正式账号能力；
6. 所有 AI 输出保留来源字段和生成模式：`ai` 或 `rule`；
7. 历史事实必须来自剧本内容系统。

# 九、接口

统一接口：

```text
POST /api/teaching-assistant
```

## 9.1 导学卡请求

```json
{
  "task": "lesson_plan",
  "scriptId": "american_revolution",
  "duration": 40,
  "studentLevel": "average",
  "teachingFocus": "区分根本原因、导火线和开始标志",
  "usageMode": "projection",
  "scriptContext": {}
}
```

## 9.2 学习复盘请求

```json
{
  "task": "learning_review",
  "scriptId": "american_revolution",
  "learningData": {
    "quizPct": 60,
    "wrongAnswers": [],
    "knowledge": [],
    "tier": "completed"
  }
}
```

## 9.3 通用响应

```json
{
  "success": true,
  "mode": "ai",
  "data": {},
  "traceId": "string"
}
```

# 十、非功能要求

## 稳定

- AI 超时不阻断页面；
- 五个原剧本不依赖 AI 才能运行；
- 新功能异常不污染原有学习数据。

## 性能

- 表单提交后立即显示加载状态；
- AI 请求超时建议 15 秒；
- 超时后直接转规则版。

## 内容

- 输出一页以内；
- 使用具体知识点；
- 不使用空泛鼓励；
- 不给学生贴标签；
- 不新增未核验史实。

## 兼容

- 桌面浏览器；
- 手机浏览器；
- 普通投影环境；
- AI 不可用时的本地模式。

# 十二、总验收

1. 老师可以从任一剧本详情页生成导学卡；
2. 导学卡包含目标、剧情、提问、板书和任务；
3. 学生完成测试后可以生成复盘卡；
4. 复盘卡使用真实错题和评级；
5. AI 失败时两类卡片仍可生成；
6. 五个原有剧本核心流程正常；
7. 页面删除不存在的云同步表述；
8. 第三方角色 IP 已完成替换或隔离；
9. 全新环境可以按 README 构建运行。
