# CMP-01｜账号会员系统 PRD

> 状态：已确认  
> 版本：V1.1  
> 本期策略：学生和教师轻账号，管理员正式账号  
> 优先级：管理员安全登录为 P0，其余云账号为 P2

---

# 一、组件结论

账号会员系统负责区分学生、教师和管理员的身份、入口、权限和数据范围。

本期采用分层策略：

- 学生使用游客身份和本机学习档案；
- 教师无需注册即可生成导学卡；
- 管理员必须通过服务端安全登录进入后台；
- 学生和教师不提供云同步；
- 管理员只能查看权限范围内的匿名互动、反馈和愿望；
- 不把浏览器本地密码包装成正式账号。

管理员登录是 CMP-08 用户互动与许愿池系统的必要前置能力。

# 四、模块 PRD

## MOD-ACC-01｜学生账号模块

### 目标

让学生无需注册即可开始学习，并在当前设备保留进度。

### 用户流程

```text
进入首页
→ 选择学生体验
→ 生成匿名设备 ID
→ 进入剧本
→ 保存本机进度
→ 返回后继续学习
```

### 功能要求

- 默认游客身份；
- 不要求姓名、手机号或邮箱；
- 首次运行生成匿名 ID；
- 使用 `DataStore` 保存本机进度；
- 清楚提示“学习进度保存在当前设备”；
- 提供清除本机学习数据入口；
- 不显示云同步承诺；
- 用户可以关闭数据改进计划；
- 关闭后不上传新增互动事件，核心学习仍可使用。

### 数据

- 本机匿名 ID；
- 剧本进度；
- 错题；
- 评级；
- 使用偏好；
- 数据改进计划开关；
- 隐私说明版本。

### 权限

学生可以：

- 体验剧本；
- 完成测试；
- 查看本机学习档案；
- 生成学习复盘；
- 提交反馈；
- 提交愿望；
- 查看审核通过的公开愿望。

学生不能：

- 访问管理员页面；
- 查看其他用户互动；
- 修改正式内容；
- 查看未审核反馈和愿望。

### 验收

- 无账号可以完成学习全流程；
- 刷新后当前设备仍能读取进度；
- 清理浏览器后不声称可以找回；
- 关闭数据改进计划后不影响剧情；
- 匿名 ID 不包含姓名、手机号和邮箱。

## MOD-ACC-02｜教师账号模块

### 目标

给教师提供导学入口和最少量的本机使用记录。

### MVP 功能

- 教师身份入口；
- 生成导学卡；
- 记住最近一次课堂时长和学生基础；
- 提交教学反馈；
- 提交剧本和功能愿望；
- P1 保存最近生成的导学卡；
- 不要求实名认证。

### 权限

教师可以：

- 读取公开剧本和知识点；
- 生成导学卡；
- 查看本机导学历史；
- 提交反馈和愿望；
- 查看公开产品路线图。

教师不能：

- 修改正式剧本；
- 修改标准答案；
- 查看其他设备学生数据；
- 访问管理员互动看板；
- 审核或删除用户愿望。

### 数据

- 本机匿名 ID；
- 最近课堂时长；
- 最近学生基础；
- 最近使用剧本；
- 本机导学卡历史；
- 数据改进计划开关。

### 验收

- 教师无需注册即可生成导学卡；
- 教师入口和学生入口清楚区分；
- 最近偏好仅保存在本机；
- 普通教师无法访问 `/admin` 页面和接口。

## MOD-ACC-03｜管理员账号模块

### 目标

保护管理员后台和用户互动数据，只允许授权人员查看、处理和导出。

### P0 能力

- 管理员登录；
- 管理员退出；
- 服务端会话；
- 登录失败提示；
- 登录限流；
- 会话过期；
- 角色权限；
- 未授权访问拦截；
- 敏感操作审计；
- 修改密码或由托管身份服务管理凭证。

### 管理员角色

#### 普通管理员

可以：

- 查看匿名用户互动；
- 查看用户选择和答题摘要；
- 查看和处理反馈；
- 审核、合并和更新愿望状态；
- 查看公开产品路线图；
- 查看基础运营指标。

不能：

- 管理其他管理员；
- 修改数据保留策略；
- 查看密码；
- 绕过审计；
- 批量导出敏感自由文本。

#### 超级管理员

除普通管理员能力外，可以：

- 创建和停用管理员；
- 分配角色；
- 管理数据保留规则；
- 审批数据导出；
- 查看完整操作审计；
- 管理事件目录中的敏感字段权限。

### 管理员登录要求

- 凭证不得保存在前端代码；
- 不使用 `localStorage` 保存管理员密码；
- 建议使用 HTTP-only 安全 Cookie；
- 生产环境必须使用 HTTPS；
- 登录接口限流；
- 连续失败触发临时锁定；
- P1 支持双因素认证；
- 所有管理员操作记录管理员 ID、时间、动作和对象。

### 数据访问边界

管理员可以查看：

- 匿名用户 ID；
- 会话与产品互动事件；
- 剧本选择；
- 答题和错题摘要；
- 用户主动提交的反馈和愿望；
- AI 导学和复盘的调用状态。

管理员不能查看：

- 用户密码；
- 浏览器完整存储；
- 屏幕录像；
- 键盘输入；
- 与产品无关的访问记录；
- 未经授权的个人联系方式。

### P2

后续建设：

- 多组织管理员；
- 学校管理员；
- 细粒度数据权限；
- 单点登录；
- 教师正式账号；
- 学生正式账号；
- 云端学习同步。

### 验收

- 未登录访问管理员页面会跳转登录；
- 未授权调用 `/api/admin/*` 返回 401 或 403；
- 普通管理员无法管理其他管理员；
- 密码和密钥不出现在前端仓库；
- 会话过期后必须重新登录；
- 管理员查看、修改和导出均有审计记录。

# 五、身份与权限模型

```json
{
  "actorId": "admin_xxx",
  "actorType": "admin",
  "role": "operator",
  "permissions": [
    "events:read",
    "feedback:read",
    "feedback:update",
    "wishes:read",
    "wishes:update"
  ]
}
```

建议权限：

- `events:read`
- `user_timeline:read`
- `feedback:read`
- `feedback:update`
- `wishes:read`
- `wishes:update`
- `wishes:merge`
- `roadmap:update`
- `exports:create`
- `admins:manage`
- `retention:update`
- `audit:read`

# 七、隐私与安全

- 学生和教师默认匿名；
- 管理员实名或内部身份登录；
- 最小权限原则；
- 管理员不能共享账号；
- 密码不进入前端日志和互动事件；
- 用户自由文本按权限查看；
- 管理员操作可追踪；
- 数据导出需要二次确认；
- 停用管理员后立即失效全部会话。
