# CMP-01｜账号会员系统 PRD

> 状态：已确认  
> 本期策略：只建立角色边界，不建设完整云账号  
> 优先级：P1 基础，合规文案修复为 P0

---

# 一、组件结论

账号会员系统负责区分学生、教师和管理员的权限、入口与数据范围。

MVP 采用轻账号策略：

- 学生使用游客身份和本机学习档案；
- 教师无需注册即可生成导学卡；
- 管理员通过仓库配置维护内容；
- 不提供云同步；
- 不把浏览器本地密码包装成正式账号。

---

# 二、组件边界

包含：

- 身份识别；
- 角色入口；
- 本机偏好；
- 权限边界；
- 登录相关产品文案。

不包含：

- 剧本内容；
- AI 生成；
- 学习评分；
- 云端用户数据库；
- 支付会员。

# 三、模块 PRD

## MOD-ACC-01｜学生账号模块

### 目标

让学生无需注册即可开始学习，并在当前设备保留进度。

### 用户流程

```text
进入首页
→ 选择游客学习
→ 进入剧本
→ 保存本机进度
→ 返回后继续学习
```

### 功能要求

- 默认游客身份；
- 不要求姓名、手机号或邮箱；
- 使用 `DataStore` 保存本机进度；
- 清楚提示“数据保存在当前设备”；
- 提供清除本机学习数据入口；
- 不显示云同步承诺。

### 数据

- 本机匿名 ID；
- 剧本进度；
- 错题；
- 评级；
- 使用偏好。

### 验收

- 无账号可以完成全流程；
- 刷新后当前设备仍能读取进度；
- 清理浏览器后不声称可以找回。

---

## MOD-ACC-02｜教师账号模块

### 目标

给教师提供导学入口和最少量的本机使用记录。

### MVP 功能

- 教师身份入口；
- 生成导学卡；
- 记住最近一次课堂时长和学生基础；
- P1 保存最近生成的导学卡；
- 不要求实名认证。

### 权限

教师可以：

- 读取公开剧本和知识点；
- 生成导学卡；
- 查看本机导学历史。

教师不能：

- 修改正式剧本；
- 修改标准答案；
- 查看其他设备学生数据。

### 验收

- 教师无需注册即可生成导学卡；
- 教师入口和学生入口清楚区分；
- 最近偏好仅保存在本机。

---

## MOD-ACC-03｜管理员账号模块

### 目标

明确内容和 AI 配置的管理权限。

### MVP 实现

管理员能力暂由 Git 仓库权限承担：

- 修改剧本注册表；
- 修改知识点；
- 修改教学元数据；
- 修改提示词；
- 修改规则模板；
- 发布版本。

### P2

后续再建设：

- 管理员登录；
- 角色权限；
- 内容审核；
- 发布审批；
- 操作日志。

### 验收

- 普通学生和教师页面无法修改正式内容；
- 所有正式配置修改可通过 Git 历史追踪。
