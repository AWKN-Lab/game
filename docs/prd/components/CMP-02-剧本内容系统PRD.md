# CMP-02｜剧本内容系统 PRD

> 状态：已确认  
> 优先级：P0  
> 核心任务：把分散在多个页面的数据收口成 AI 与产品共同使用的内容底座

---

# 一、组件结论

剧本内容系统管理五个现有剧本、知识点、幕次、角色、资源和教学元数据。

本期不重写全部剧本格式。先统一元数据和教学字段，避免重复维护和口径漂移。

---

# 二、组件边界

包含：

- 剧本注册；
- 课程库展示；
- 知识点；
- 教学元数据；
- 角色配置；
- 图片、音频等内容资产索引。

不包含：

- 剧情播放；
- 学习数据；
- AI 推理；
- 用户权限。

---

# 三、模块 PRD

## MOD-CONTENT-01｜剧本注册与课程库模块

### 目标

建立唯一剧本清单，所有页面读取同一份数据。

### 当前剧本

- 法国大革命；
- 美国独立战争；
- 工业革命；
- 戊戌变法；
- 辛亥革命。

### 数据字段

```js
{
  id,
  name,
  file,
  subtitle,
  era,
  grade,
  duration,
  difficulty,
  knowledgePoints,
  collectibles,
  heroImage,
  endings,
  teaching
}
```

### 功能要求

- `script-select.html` 从注册表渲染；
- `script-detail.html` 从注册表渲染；
- `my-learning.html` 从注册表渲染；
- 删除页面内重复的剧本数组；
- 知识点数量以真实数据计算。

### 验收

- 五个页面对同一剧本显示一致；
- 戊戌变法、辛亥革命知识点数量保持一致；
- 新增剧本只需要注册一次。

---

## MOD-CONTENT-02｜知识点与教学元数据模块

### 目标

让 AI 可以从现有内容中选择课堂重点，避免自由编造。

### 知识点字段

现有字段：

- `id`
- `name`
- `content`
- `act`
- `exam`
- `answerTips`

新增字段：

```json
{
  "commonMistakes": [],
  "teacherPrompts": [],
  "prerequisites": [],
  "relatedKnowledgeIds": [],
  "lessonPriority": "core"
}
```

### 教学元数据

每个剧本增加：

- 15 分钟建议幕次；
- 20 分钟建议幕次；
- 40 分钟建议幕次；
- 基础薄弱重点；
- 基础较好重点；
- 推荐板书；
- 课后任务模板。

### 验收

- AI 导学输入不需要解析整份 HTML；
- 每个主演示剧本至少有完整教学元数据；
- 所有推荐知识点都能在知识库中找到。

---

## MOD-CONTENT-03｜角色与内容资产模块

### 目标

统一原创角色、人物立绘、背景、音频和内容路径。

### 功能要求

- 使用子衿、洛书作为原创引导角色；
- 建立旧 ID 到新角色的兼容映射；
- 清理第三方世界观专属台词；
- 资产路径统一；
- 大资源缺失时提供静态降级图。

### 验收

- 首页和主演示剧本不出现第三方角色名；
- 旧剧本无需大规模改写即可显示新角色；
- 资源缺失时页面仍能继续学习。

---

# 四、数据源原则

- `script-registry.js`：产品元数据唯一来源；
- `data/knowledge_points.json`：知识点唯一来源；
- `data/teaching_metadata.json`：教学元数据唯一来源；
- 剧本 HTML：剧情正文和互动事件；
- 页面禁止继续硬编码完整剧本清单。

---

# 五、不做

- 全量内容管理后台；
- AI 自动发布新剧本；
- 所有剧本一次性迁移为 JSON；
- 教材全章节覆盖。
