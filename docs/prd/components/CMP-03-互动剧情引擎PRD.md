# 一、组件结论

互动剧情引擎是时空剧场的核心运行时。

V2.0 核心体验主张：**选择被记住（后果密度）**。引擎从"线性推进 + 结局结算"升级为"单线时间轴 + 可感知后果"：选择改变 NPC 命运、资源状态与后续台词回响，失败可玩，人物信任可见。不做全树分支，课标史实 100% 保留在主时间轴。

原 MVP 范围（五剧本稳定运行、规范事件）继续有效。

# 二、组件边界

包含：

- 对话推进；
- 场景与角色渲染；
- 背景和音频；
- 选择；
- 证据调查；
- 限时选择；
- 知识点；
- NPC 命运；
- 结局；
- 知识测试。

不包含：

- 导学卡生成；
- 学生复盘文案；
- 用户账号；
- 内容后台。

# 三、模块 PRD

## MOD-ENGINE-01｜剧情运行模块

### 目标

稳定播放现有五个剧本。

### 功能

- 加载 `GAME_CONFIG`；
- 加载 `DIALOG_SCRIPT`；
- 推进对话；
- 场景切换；
- 角色显示；
- 语音和 BGM；
- 断点续玩；
- 异常时文本降级。

### 验收

- 五个剧本可以从开始运行到结局；
- 无语音时可以继续；
- 背景资源失败不阻断对话；
- 手机和桌面可操作。

## MOD-ENGINE-02｜互动事件模块

### 支持事件

- `choice`
- `card_choice`
- `evidence`
- `pressure_choice`
- `knowledge`
- `collectible`
- `npc_fate_event`
- `act_transition`

### 本期更新

为关键事件增加统一事件记录：

```js
GameEvents.emit({
  scriptId,
  eventType,
  dialogIndex,
  nodeId,
  payload,
  timestamp
});
```

该记录供学习数据组件使用，不改变原有剧情结果。

### 验收

- 普通选择和知识测试可以产生结构化记录；
- 事件记录失败不影响剧情；
- 不重复记录同一次点击。

- 错题保存；
- 学习评级；

### 本期更新

- 统一五个剧本测试字段格式；
- 保证 `question/options/answer/explanation` 与 `q/opts/ans/explain` 兼容；

# 五、V2.0 新增模块 PRD

## MOD-ENGINE-04｜后果密度与回响模块（P1）

### 目标

让每个关键选择在后续幕次产生可感知后果，替代"选择后 dialogIndex++ 线性推进"的假选择。

### 功能

- 选择后果登记：每个关键选择登记后果清单（NPC 命运变化 / 资源状态变化 / 回响台词锚点）；
- 回响触发：后续幕次按锚点回读玩家历史选择，插入回响台词或场景变化；回响内容由 CMP-05 生成回响模块产出，规则版模板兜底；
- 失败可玩（fail-forward）：错误选择付出叙事代价（NPC 信任下降、资源损失、目睹负面后果），剧情继续，不新增分支、不判负重开；
- 单线保障：所有后果发生在同一时间轴上，课标要求史实 100% 出现在主时间轴。

### 验收

- 每幕 ≥ 1 处可感知后果；
- 第三幕回响台词与玩家第一幕选择相关率 100%（规则版同样达标）；
- 任一选择的后果清单可在剧本元数据中追溯；
- 五个原剧本回归不受影响。

## MOD-ENGINE-05｜人物信任模块（P1）

### 目标

把隐藏数值转化为可见的人物信任，替代"属性门槛置灰"。

### 功能

- 每个 NPC 维护信任状态（复用现有数值，仅作结算）；
- 信任变化以叙事方式呈现：信任你的人会透露消息、求你办事、在结局为你作证；不信任你的人会拒绝、隐瞒、提防；
- 信任不足不置灰选项，而是让 NPC 以角色身份拒绝或提出条件；
- 信任轨迹写入事件 `trust_level_changed`，供复盘卡引用。

### 验收

- 玩家全程不看到数值条，但能说出每个关键 NPC 对自己的态度；
- 信任变化均有剧情因果可追溯；
- 结局判定继续使用幕后数值，口径不变。

## MOD-ENGINE-06｜课堂皮呈现模块（P1）

### 目标

同一引擎、同一剧情数据，提供课堂皮（绘本/课件模式）与课后皮（游戏模式）两套呈现。

### 功能

- 课堂皮：投影友好排版、无积分、无排行榜、无游戏化元素、可导出学情摘要；
- 课后皮：现有游戏模式完整保留；
- 两套皮共享剧情数据与存档结构，切换不丢进度。

### 验收

- 投影环境可运行课堂皮；
- 课堂皮中不出现积分与游戏化元素；
- 切换皮肤后学习进度完整。
