# CMP-05｜AI 教学助手 PRD

> 状态：已确认  
> 优先级：P0 核心增量  
> 组件目标：把现有剧本变成老师会用、学生能复盘的教学材料

---

# 一、组件结论

AI 教学助手包含三个模块：

1. 教师导学卡；
2. 学生学习复盘卡；
3. AI 安全与规则降级。

AI 使用结构化剧本内容和真实学习数据，不自由生成历史剧情。

---

# 二、模块 PRD

## MOD-AI-01｜教师导学卡模块

### 用户

历史或道法教师。

### 场景

老师已经选定一个时空剧场剧本，需要快速整理一节课怎么使用。

### 输入

- 剧本；
- 课堂时长：15、20、40 分钟；
- 学生基础：薄弱、一般、较好；
- 教学重点；
- 使用方式：投屏或学生自学。

### 输出

```json
{
  "objectives": [],
  "recommendedActs": [],
  "pauseQuestions": [],
  "blackboard": [],
  "summary": "",
  "homework": ""
}
```

### 页面要求

- 入口位于剧本详情页；
- 表单一屏完成；
- 生成时展示进度；
- 输出一页以内；
- 支持再次生成；
- 标识 AI 版或规则版。

### 内容规则

- 每个建议必须能追溯到现有知识点；
- 暂停问题最多 3 个；
- 板书使用短句；
- 教学重点为空时使用剧本核心知识；
- 不输出完整长教案。

### 验收

- 《美国独立战争》四十分钟场景可以生成完整导学卡；
- 其他四个剧本可以生成基础导学卡；
- AI 失败仍有规则版。

---

## MOD-AI-02｜学生学习复盘卡模块

### 用户

完成剧本和测试的学生。

### 输入

- 剧本；
- 完成情况；
- 知识点；
- 测试正确率；
- 错题；
- 学习评级；
- 游戏时长。

### 输出

```json
{
  "mastered": [],
  "confusions": [],
  "errorReason": "",
  "nextActions": [],
  "nextScript": {
    "id": "",
    "reason": ""
  }
}
```

### 页面要求

- 入口位于测试完成页和我的学习页；
- 没有测试数据时提示先完成测试；
- 错因引用具体题目或知识点；
- 下一步最多 3 项；
- 推荐下一剧本必须来自注册表。

### 语言规则

- 使用“你已经掌握”“你容易混淆”；
- 禁止使用笨、差、没有天赋等词；
- 避免空泛表扬；
- 解释控制在学生可以读懂的长度。

### 验收

- 错题为零时输出迁移建议；
- 错题存在时至少指出一个具体混淆；
- 不编造学生没有产生的数据。

---

## MOD-AI-03｜AI 安全与规则降级模块

### 目标

保证模型失败、超时或输出不合格时，产品仍可使用。

### AI 输入约束

只发送：

- 剧本元数据；
- 相关知识点；
- 教学条件；
- 必要学习数据。

不发送：

- 学生真实姓名；
- 密码；
- 无关本机数据；
- 完整浏览历史。

### 输出校验

- JSON Schema；
- 字段完整；
- 知识点 ID 存在；
- 推荐剧本 ID 存在；
- 输出长度限制；
- 敏感和伤害性语言检查。

### 降级触发

- 请求超时；
- HTTP 错误；
- JSON 解析失败；
- 必填字段缺失；
- 引用了不存在的知识点；
- 内容安全检查失败。

### 规则版

导学卡根据：

- 时长；
- 学生基础；
- 教学元数据；

生成固定结构。

复盘卡根据：

- 正确率区间；
- 错题知识点；
- 学习评级；

生成固定结构。

### 验收

- 断网环境可以生成规则版；
- 页面不暴露模型错误堆栈；
- 返回数据包含 `mode: ai | rule`；
- 记录 `traceId` 便于排查。

# 三、接口

```text
POST /api/teaching-assistant
```

任务类型：

- `lesson_plan`
- `learning_review`

统一超时建议：15 秒。

---

# 四、不做

- 自由生成新剧本；
- 自动改标准答案；
- 自动给学生人格画像；
- 自动给教师打分；
- 长篇教案生成。
