# CMP-05｜AI 教学助手 PRD

> 状态：已确认（V2.0 新增叙事 AI 模块）  
> 优先级：P0 核心增量 + P1 V2.0 增量  
> 组件目标：把现有剧本变成老师会用、学生能复盘的教学材料；V2.0 起承担叙事表达层

---

# 一、组件结论

AI 教学助手包含六个模块：

1. 教师导学卡；
2. 学生学习复盘卡；
3. AI 安全与规则降级；
4. AI NPC 对话（V2.0）；
5. 生成回响（V2.0）；
6. 历史审稿人（V2.0）。

AI 使用结构化剧本内容和真实学习数据，**不生成历史事实**：事实层锚定剧本内容系统，AI 只做表达层。AI 的角色限定为对手、证人、审稿人——逼学生思考，不替学生思考。

---

# 二、模块 PRD

## MOD-AI-01｜教师导学卡模块

### 用户

历史或道法教师。

### 场景

老师已经选定一个时空剧场剧本，需要快速整理一节课怎么使用。

### 输入

- 剧本；
- 课堂时长：15、20、40 分钟；
- 学生基础：薄弱、一般、较好；
- 教学重点；
- 使用方式：投屏或学生自学。

### 输出

```json
{
  "objectives": [],
  "recommendedActs": [],
  "pauseQuestions": [],
  "blackboard": [],
  "summary": "",
  "homework": ""
}
```

### 页面要求

- 入口位于剧本详情页；
- 表单一屏完成；
- 生成时展示进度；
- 输出一页以内；
- 支持再次生成；
- 标识 AI 版或规则版。

### 内容规则

- 每个建议必须能追溯到现有知识点；
- 暂停问题最多 3 个；
- 板书使用短句；
- 教学重点为空时使用剧本核心知识；
- 不输出完整长教案。

### 验收

- 《美国独立战争》四十分钟场景可以生成完整导学卡；
- 其他四个剧本可以生成基础导学卡；
- AI 失败仍有规则版。

## MOD-AI-02｜学生学习复盘卡模块

### 用户

完成剧本和测试的学生。

### 输入

- 剧本；
- 完成情况；
- 知识点；
- 测试正确率；
- 错题；
- 学习评级；
- 游戏时长。

### 输出

```json
{
  "mastered": [],
  "confusions": [],
  "errorReason": "",
  "nextActions": [],
  "nextScript": {
    "id": "",
    "reason": ""
  }
}
```

### 页面要求

- 入口位于测试完成页和我的学习页；
- 没有测试数据时提示先完成测试；
- 错因引用具体题目或知识点；
- 下一步最多 3 项；
- 推荐下一剧本必须来自注册表。

### 语言规则

- 使用“你已经掌握”“你容易混淆”；
- 禁止使用笨、差、没有天赋等词；
- 避免空泛表扬；
- 解释控制在学生可以读懂的长度。

### 验收

- 错题为零时输出迁移建议；
- 错题存在时至少指出一个具体混淆；
- 不编造学生没有产生的数据。

## MOD-AI-03｜AI 安全与规则降级模块

### 目标

保证模型失败、超时或输出不合格时，产品仍可使用。

### AI 输入约束

只发送：

- 剧本元数据；
- 相关知识点；
- 教学条件；
- 必要学习数据。

不发送：

- 学生真实姓名；
- 密码；
- 无关本机数据；
- 完整浏览历史。

### 输出校验

- JSON Schema；
- 字段完整；
- 知识点 ID 存在；
- 推荐剧本 ID 存在；
- 输出长度限制；
- 敏感和伤害性语言检查。

### 降级触发

- 请求超时；
- HTTP 错误；
- JSON 解析失败；
- 必填字段缺失；
- 引用了不存在的知识点；
- 内容安全检查失败。

### 规则版

导学卡根据：

- 时长；
- 学生基础；
- 教学元数据；

生成固定结构。

复盘卡根据：

- 正确率区间；
- 错题知识点；
- 学习评级；

生成固定结构。

### 验收

- 断网环境可以生成规则版；
- 页面不暴露模型错误堆栈；
- 返回数据包含 `mode: ai | rule`；
- 记录 `traceId` 便于排查。

# 四、V2.0 新增模块 PRD

## MOD-AI-04｜AI NPC 对话模块（P1）

### 用户

剧本进行中的学生。

### 场景

学生想追问、说服或反驳历史人物 NPC，而不是只从三个选项里挑一个。

### 输入

- NPC 人设卡（来自剧本内容系统，含立场、知识边界、口头禅）；
- 当前剧情节点与玩家选择历史；
- 玩家自由输入；
- 信任状态（影响 NPC 态度）。

### 输出

- NPC 回复（符合人设与时代语言）；
- 回复类型标记：正常对话 / 拒绝（信任不足）/ 提出条件。

### 硬边界

- NPC 不透露剧本知识库以外的"史实"；
- NPC 不做价值评判式说教，不替学生做决定；
- 玩家自由输入先过内容安全检查。

### 验收

- 自由输入参与率 ≥ 30%，对话轮数中位数 ≥ 3；
- AI 失败自动降级为规则版回复（预设台词池），剧情不中断；
- 输出与剧本知识库冲突率 = 0。

## MOD-AI-05｜生成回响模块（P1）

### 用户

剧情推进中的学生。

### 场景

后续幕次需要根据玩家第一幕的选择生成回响台词，替代写死的固定文案。

### 输入

- 玩家选择历史（结构化事件）；
- 回响锚点（剧本元数据登记）；
- 规则版回响模板。

### 输出

- 回响台词（一至两句，可引用玩家具体行为）；
- 规则版兜底：按锚点从模板库选取。

### 验收

- 回响与玩家选择相关率 100%（AI 版与规则版均达标）；
- 生成失败时使用规则版模板，不出现占位文案；
- 回响触发写入事件 `echo_referenced`。

## MOD-AI-06｜历史审稿人模块（P1）

### 用户

系统（旁路调用）与教师。

### 场景

学生自由输入可能包含穿越言论、史实错误或不当内容，需要在进入对话前校验。

### 输入

- 学生自由输入；
- 剧本知识库（该剧本的史实与时代边界）。

### 输出

```json
{
  "verdict": "pass | anachronism | factual_error | unsafe",
  "reason": "",
  "suggestion": ""
}
```

### 规则

- `unsafe` 直接拦截，不进入 NPC 对话；
- `anachronism` / `factual_error` 由 NPC 以角色身份回应（如困惑、纠正），不显示"判定卡片"；
- 审稿结果写入事件 `fact_check_flagged`，供教师端查看；
- 审稿人只对照剧本知识库，不引入外部史实判断。

### 验收

- AI 输出与剧本知识库冲突率 = 0（审稿拦截后）；
- 拦截不惩罚、不扣分，以叙事方式化解；
- 教师可在学情摘要中看到被标记的输入统计。

# 五、不做（V2.0 修订）

- 自由生成新剧本；
- AI 生成历史事实（事实层只来自剧本内容系统）；
- AI 替学生做价值判断或给学生的历史观点打分；
- 自动改标准答案；
- 自动给学生人格画像；
- 自动给教师打分；
- 长篇教案生成。
