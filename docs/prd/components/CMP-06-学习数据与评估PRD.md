# CMP-06｜学习数据与评估 PRD

> 状态：已确认  
> 优先级：P0  
> 核心任务：让学生复盘建立在真实学习数据上

---

# 一、组件结论

学习数据与评估组件管理进度、错题、知识掌握、测试成绩、评级和报告输入。

MVP 继续使用本机 `localStorage`，不宣称云同步。

---

# 二、组件边界

包含：

- 剧本进度；
- 结局；
- 收集品；
- 知识点状态；
- 错题；
- 测试成绩；
- 学习评级；
- 复盘输入聚合。

不包含：

- 剧情渲染；
- AI 文案生成；
- 用户密码；
- 内容编辑。

---

# 三、模块 PRD

## MOD-DATA-01｜学习进度模块

### 功能

- 保存剧本 ID；
- 保存对话索引；
- 保存游戏数值；
- 保存收集品；
- 保存当前幕；
- 继续游戏；
- 保存完成结局；
- 统计游戏时长。

### 本期更新

- 增加数据版本号；
- 增加匿名设备 ID；
- 修复总游戏时长被多个剧本共享的口径；
- 为每个剧本单独记录时长。

### 验收

- 五个剧本进度互不覆盖；
- 旧数据能够兼容读取；
- 数据损坏时使用默认值。

---

## MOD-DATA-02｜错题与知识掌握模块

### 功能

错题记录：

- 题目；
- 用户答案；
- 正确答案；
- 解析；
- 剧本；
- 知识点 ID；
- 时间。

知识掌握：

- 知识点 ID；
- 已接触；
- 答对次数；
- 答错次数；
- 最近结果。

### 本期更新

现有布尔型掌握状态升级为可统计结构，同时保留旧 API 兼容。

### 验收

- 复盘卡能够按知识点聚合错题；
- 同一道题重复答错不会丢失历史；
- 可以清除本机错题。

---

## MOD-DATA-03｜学习评级与报告模块

### 目标

统一整理复盘卡需要的数据。

### 评级输入

- 客观题正确率；
- 论述题槽位；
- 剧情完成；
- 尝试次数；
- 最佳成绩。

### 报告聚合 API

```js
DataStore.getLearningReviewContext(scriptId)
```

返回：

```json
{
  "scriptId": "",
  "completed": true,
  "quizPct": 0,
  "wrongAnswers": [],
  "knowledgeSummary": [],
  "tier": "",
  "attemptCount": 0,
  "playTime": 0
}
```

### 验收

- AI 教学助手只调用一个聚合 API；
- 数据缺失时字段有默认值；
- 报告不包含密码和无关账号数据；
- 结果可以导出为 JSON，P1 支持打印。

---

# 四、隐私

- 默认匿名；
- 数据保存在当前设备；
- 用户可以清除；
- AI 请求使用最小字段；
- 不建立未成年人画像；
- 不做跨设备追踪。

---

# 五、不做

- 云端学生档案；
- 班级排名；
- 公开排行榜；
- 教师查看全班个人数据；
- 商业广告画像。
