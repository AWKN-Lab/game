# CMP-06｜学习数据与评估 PRD

> 状态：已确认  
> 版本：V1.1  
> 优先级：P0  
> 核心任务：让学生复盘建立在真实学习数据上，并向管理员输出经过定义的学习事件

---

# 一、组件结论

学习数据与评估组件管理进度、错题、知识掌握、测试成绩、评级和报告输入。

本期采用双层数据结构：

1. **本机学习档案**：继续使用 `localStorage`，服务学生续玩和个人复盘；
2. **云端互动事件**：在用户知情的前提下，将经过定义的学习事件发送给 CMP-08，用于管理员查看产品使用情况和改进内容。

云端互动事件不等于学生云档案。

系统不宣称学习进度可以跨设备同步。

---

# 二、组件边界

## 2.1 包含

- 剧本进度；
- 结局；
- 收集品；
- 知识点状态；
- 错题；
- 测试成绩；
- 学习评级；
- 复盘输入聚合；
- 学习事件标准化；
- 向事件 SDK 输出白名单字段；
- 用户清除本机学习数据。

## 2.2 不包含

- 剧情渲染；
- AI 文案生成；
- 用户密码；
- 内容编辑；
- 管理员看板；
- 用户反馈；
- 许愿池；
- 云端学生正式档案；
- 跨设备学习同步。

管理员看板、反馈和许愿由 CMP-08 负责。

# 四、模块 PRD

## MOD-DATA-01｜学习进度模块

### 功能

- 保存剧本 ID；
- 保存对话索引；
- 保存游戏数值；
- 保存收集品；
- 保存当前幕；
- 继续游戏；
- 保存完成结局；
- 统计游戏时长；
- 输出剧本开始、继续、幕次到达和完成事件。

### 本期更新

- 增加数据版本号；
- 增加匿名设备 ID；
- 修复总游戏时长被多个剧本共享的口径；
- 为每个剧本单独记录时长；
- 增加事件发送状态，不影响本机原始进度；
- 增加数据改进计划开关；
- 关闭数据改进计划时只保留本机数据。

### 学习进度事件

- `script_started`
- `script_resumed`
- `act_reached`
- `script_completed`
- `ending_unlocked`

### 事件字段

```json
{
  "scriptId": "american_revolution",
  "actId": "act_03",
  "progressPct": 60,
  "playTimeSec": 840,
  "endingType": null
}
```

不上传：

- 本机完整存档；
- 页面缓存；
- 密码；
- 与事件无关的浏览器字段。

### 验收

- 五个剧本进度互不覆盖；
- 旧数据能够兼容读取；
- 数据损坏时使用默认值；
- 事件上报失败不影响续玩；
- 关闭数据改进计划后不再上传新学习事件。

---

## MOD-DATA-02｜错题与知识掌握模块

### 功能

错题记录：

- 题目 ID；
- 用户答案索引；
- 正确答案索引；
- 解析；
- 剧本；
- 知识点 ID；
- 时间；
- 尝试次数。

知识掌握：

- 知识点 ID；
- 已接触；
- 答对次数；
- 答错次数；
- 最近结果；
- 最近学习时间。

### 本期更新

现有布尔型掌握状态升级为可统计结构，同时保留旧 API 兼容。

输出事件：

- `knowledge_point_viewed`
- `quiz_started`
- `quiz_answered`
- `quiz_completed`

### `quiz_answered` 事件

```json
{
  "scriptId": "american_revolution",
  "questionId": "ar_q_02",
  "knowledgeIds": ["ar_h1"],
  "selectedIndex": 1,
  "correct": false,
  "attempt": 1,
  "elapsedMs": 12000
}
```

默认不上传完整题目文本和长解析，管理员通过 `questionId` 关联正式题库。

### 管理员可见范围

管理员可以查看：

- 某知识点答对和答错次数；
- 某题的选择分布；
- 匿名用户的答题顺序；
- 剧本和幕次上下文；
- 聚合正确率。

管理员不能查看：

- 学生真实姓名；
- 本机完整错题本；
- 与产品无关的数据；
- 未经授权的私人信息。

### 验收

- 复盘卡能够按知识点聚合错题；
- 同一道题重复答错不会丢失历史；
- 可以清除本机错题；
- 管理员能按题目和知识点查看匿名聚合；
- 题目文本更新后历史事件仍可通过 ID 关联。

## MOD-DATA-03｜学习评级与报告模块

### 目标

统一整理学生复盘卡需要的数据，并输出报告生成事件。

### 评级输入

- 客观题正确率；
- 论述题槽位；
- 剧情完成；
- 尝试次数；
- 最佳成绩。

### 报告聚合 API

```js
DataStore.getLearningReviewContext(scriptId)
```

返回：

```json
{
  "scriptId": "",
  "completed": true,
  "quizPct": 0,
  "wrongAnswers": [],
  "knowledgeSummary": [],
  "tier": "",
  "attemptCount": 0,
  "playTime": 0
}
```

### 事件输出

- `learning_review_requested`
- `learning_review_generated`
- `learning_review_failed`
- `learning_review_rule_fallback`

事件只保存：

- 剧本 ID；
- 生成模式；
- 是否成功；
- 耗时；
- 知识点数量；
- 错题数量；
- 评级；
- traceId。

P0 默认不把完整学生复盘文案作为行为事件保存。

如后续需要保存完整输出，必须单独说明用途、保留周期和访问权限。

### 验收

- AI 教学助手只调用一个聚合 API；
- 数据缺失时字段有默认值；
- 报告不包含密码和无关账号数据；
- 结果可以导出为 JSON，P1 支持打印；
- 管理员能看到复盘是否生成成功和使用 AI 还是规则版；
- 管理员默认看不到不必要的完整复盘自由文本。

# 五、本机数据与云端事件的关系

| 数据 | 本机保存 | 云端事件 | 管理员可见 |
|---|---:|---:|---:|
| 当前对话索引 | 是 | 否 | 否 |
| 当前幕次 | 是 | 幕次到达事件 | 是 |
| 完整游戏数值 | 是 | 否 | 否 |
| 选择结果 | 是或即时使用 | 选择事件 | 是 |
| 完整错题文本 | 是 | 默认否 | 默认否 |
| 题目 ID 与结果 | 是 | 是 | 是 |
| 知识点掌握 | 是 | 聚合事件 | 是 |
| 学习评级 | 是 | 是 | 是 |
| 完整复盘文案 | 是或临时显示 | 默认否 | 默认否 |
| 复盘生成状态 | 是 | 是 | 是 |

# 六、隐私

- 默认匿名；
- 数据保存在当前设备；
- 用户可以清除；
- AI 请求使用最小字段；
- 互动事件使用白名单字段；
- 用户可以关闭数据改进计划；
- 不建立未成年人商业画像；
- 不做跨站追踪；
- 不采集屏幕录像；
- 不采集键盘输入；
- 不将匿名数据与外部广告 ID 关联；
- 管理员访问数据必须通过 CMP-01 权限校验。

---

# 七、与 CMP-08 的接口

建议统一使用：

```js
Analytics.track(eventName, payload)
```

批量发送：

```text
POST /api/events/batch
```

要求：

- 事件 ID 幂等；
- 离线队列；
- 批量上报；
- 失败重试；
- 退出前尽力发送；
- 不阻塞主线程；
- 不影响剧情推进。

# 八、不做

- 云端学生正式档案；
- 跨设备学习同步；
- 班级排名；
- 公开排行榜；
- 教师查看全班个人数据；
- 商业广告画像；
- 心理健康自动推断；
- 家庭条件推断；
- 将匿名事件出售或提供给广告商。
