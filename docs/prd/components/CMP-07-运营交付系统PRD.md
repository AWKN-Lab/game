# 一、组件结论

运营交付系统负责内容配置、AI 配置、构建、部署、资源加载和离线降级。

当前仓库引用 `dist/output.css`，但发布导入排除了 `dist/`，同时缺少完整构建脚本。本期必须先修复可复现性。

---

# 二、模块 PRD

## MOD-OPS-01｜内容与 AI 配置模块

### 目标

将频繁调整的内容放入可追踪配置。

### 配置文件

建议新增：

```text
data/teaching_metadata.json
data/ai_prompts.json
data/rule_templates.json
data/character_aliases.json
```

### 管理方式

MVP 使用 Git：

- 修改；
- 代码审查；
- 合并；
- 发布；
- 回滚。

### 验收

- 提示词修改无需改页面 HTML；
- 规则模板可单独测试；
- 配置有版本字段；
- 配置错误有默认值。

---

## MOD-OPS-02｜构建部署模块

### 目标

全新环境可以按 README 运行项目。

### 必须新增

- Tailwind 输入文件；
- `npm run build:css`；
- `npm run build`；
- `npm run check`；
- README 启动步骤；
- 基础内容校验脚本。

### 验收命令

```bash
npm ci
npm run build
npm run check
```

### 检查内容

- 注册表中的页面文件存在；
- 知识点数量正确；
- 必填字段完整；
- 图片路径基础检查；
- AI 配置 JSON 合法；
- 不包含密钥。

### 部署

- 构建产物由 CI 或服务器生成；
- 不依赖开发者本机的历史 `dist`；
- 生产部署保留回滚版本。

---

## MOD-OPS-03｜轻量运行与离线降级模块

### 目标

普通网络和比赛现场异常时，核心流程仍能运行。

### MVP

- AI 失败转规则版；
- 语音失败转文字；
- 图片失败显示背景色；
- 第三方字体失败使用系统字体；
- 知识星系失败显示知识点列表。

### P1

- D3 和 Three.js 本地化；
- 资源按剧本加载；
- 轻量模式；
- Service Worker 缓存；
- 导学卡和复盘卡打印。

### 验收

- 关闭 AI 接口后仍可演示完整闭环；
- 关闭语音后剧情继续；
- 知识星系加载失败不白屏；
- 手机端主要按钮可操作。
