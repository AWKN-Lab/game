# 一、组件结论

运营交付系统负责内容配置、AI 配置、构建、部署、资源加载、服务端运行和异常降级。

当前仓库引用 `dist/output.css`，但发布导入排除了 `dist/`，同时缺少完整构建脚本。本期必须先修复可复现性。

新增管理员互动与许愿池后，运营交付系统还需要承担：

- 管理员认证服务部署；
- 互动事件接收服务；
- 反馈与愿望接口；
- 数据库迁移；
- 数据保留和清理任务；
- 基础服务日志与健康检查；
- 密钥管理；
- 管理后台静态资源发布。

# 四、模块 PRD

## MOD-OPS-01｜内容与 AI 配置模块

### 目标

将频繁调整的内容放入可追踪配置。

### 配置文件

建议新增：

```text
data/teaching_metadata.json
data/ai_prompts.json
data/rule_templates.json
data/character_aliases.json
data/event_catalog.json
data/privacy_copy.json
data/wish_categories.json
data/retention_policy.json
```

### 配置职责

#### `event_catalog.json`

定义：

- 允许上报的事件名；
- 允许的 payload 字段；
- 字段类型；
- 是否包含自由文本；
- 数据用途；
- 保留周期；
- 是否需要用户知情；
- 管理员可见级别。

#### `wish_categories.json`

定义：

- 剧本愿望分类；
- 功能愿望分类；
- 问题愿望分类；
- 默认状态；
- 公开规则。

#### `retention_policy.json`

定义：

- 原始事件保留周期；
- 反馈保留周期；
- 愿望保留周期；
- 审计日志保留周期；
- 清理任务频率。

### 管理方式

MVP 使用 Git：

- 修改；
- 代码审查；
- 合并；
- 发布；
- 回滚。

### 验收

- 提示词修改无需改页面 HTML；
- 规则模板可单独测试；
- 事件目录可单独校验；
- 未注册事件无法通过校验；
- 许愿分类可通过配置更新；
- 配置有版本字段；
- 配置错误有默认值；
- 密钥不进入配置文件和仓库。

## MOD-OPS-02｜构建部署模块

### 目标

全新环境可以按 README 运行前端、API、管理员后台和数据服务。

### 前端必须新增

- Tailwind 输入文件；
- `npm run build:css`；
- `npm run build`；
- `npm run check`；
- README 启动步骤；
- 基础内容校验脚本；
- 管理后台构建入口；
- 用户反馈和许愿池页面构建检查。

### 服务端必须具备

- AI 教学助手接口；
- 事件批量接收接口；
- 反馈接口；
- 许愿池接口；
- 管理员认证；
- 管理员查询和更新接口；
- 审计日志；
- 数据库迁移；
- 健康检查；
- 限流；
- 输入校验；
- 统一错误响应。

### 推荐脚本

```json
{
  "scripts": {
    "build:css": "tailwindcss -i ./styles/input.css -o ./dist/output.css --minify",
    "build:web": "npm run build:css",
    "build": "npm run build:web",
    "check:content": "node scripts/validate-content.mjs",
    "check:events": "node scripts/validate-event-catalog.mjs",
    "check": "npm run check:content && npm run check:events",
    "test": "node --test",
    "start": "node server/index.mjs"
  }
}
```

具体技术栈由工程设计确认，但必须提供等价能力。

### 本地验收命令

```bash
npm ci
npm run build
npm run check
npm test
npm start
```

### 检查内容

- 注册表中的页面文件存在；
- 知识点数量正确；
- 必填字段完整；
- 图片路径基础检查；
- AI 配置 JSON 合法；
- 事件目录合法；
- 事件 payload 不允许未知字段；
- 许愿分类合法；
- 数据保留配置合法；
- 管理接口全部有认证中间件；
- 不包含密钥；
- 不包含前端硬编码管理员密码。

### 环境

至少区分：

- 本地开发；
- 预发布；
- 生产。

环境变量示例：

```text
AI_API_KEY
DATABASE_URL
SESSION_SECRET
ADMIN_BOOTSTRAP_EMAIL
ADMIN_BOOTSTRAP_PASSWORD_HASH
APP_BASE_URL
LOG_LEVEL
```

仓库只保留 `.env.example`，不得提交真实值。

### 数据库迁移

建议包含：

- `admins`
- `admin_sessions`
- `interaction_events`
- `feedback`
- `wishes`
- `wish_votes`
- `wish_relations`
- `audit_logs`

迁移要求：

- 可重复执行；
- 有版本号；
- 支持回滚或前向修复；
- 生产迁移前备份；
- 字段变更同步 PRD 和事件目录。

### 部署

- 构建产物由 CI 或服务器生成；
- 不依赖开发者本机的历史 `dist`；
- 前端、API 和数据库版本可追踪；
- 生产部署保留回滚版本；
- 管理员后台不得暴露源码密钥；
- API 必须使用 HTTPS；
- 登录 Cookie 使用安全属性；
- 管理路径可公开访问登录页，但数据接口必须鉴权。

### CI 门禁

```text
安装依赖
→ 构建前端
→ 校验内容
→ 校验事件目录
→ 单元测试
→ API 权限测试
→ 数据库迁移检查
→ 密钥扫描
→ 生成部署产物
```

### 验收

- 全新环境按 README 可启动；
- 前端、API 和管理员后台均能访问；
- 未登录管理接口返回 401；
- 普通用户无法读取事件和反馈列表；
- 数据库迁移成功；
- 环境变量缺失时给出明确错误；
- 生产构建中没有真实密钥；
- 可以回滚到上一版本。

## MOD-OPS-03｜轻量运行与离线降级模块

### 目标

普通网络和比赛现场异常时，核心学习流程仍能运行；互动事件稍后补发。

### MVP

- AI 失败转规则版；
- 语音失败转文字；
- 图片失败显示背景色；
- 第三方字体失败使用系统字体；
- 知识星系失败显示知识点列表；
- 事件接口失败进入本机队列；
- 网络恢复后批量重试；
- 重试使用 `eventId` 幂等；
- 反馈和许愿提交失败保留草稿；
- 管理员后台服务异常显示健康状态，不显示伪数据。

### 事件离线队列

建议结构：

```json
{
  "eventId": "evt_xxx",
  "eventName": "choice_selected",
  "createdAt": 0,
  "retryCount": 0,
  "nextRetryAt": 0,
  "payload": {}
}
```

### 重试规则

- 首次失败后延迟重试；
- 指数退避；
- 最大重试次数；
- 达到上限后保留诊断信息；
- 不无限增长本机队列；
- 事件超出保留期后删除；
- 退出页面前使用合适的非阻塞发送方式。

### P1

- D3 和 Three.js 本地化；
- 资源按剧本加载；
- 轻量模式；
- Service Worker 缓存；
- 导学卡和复盘卡打印；
- 反馈和愿望离线提交；
- 管理员只读应急模式。

### 验收

- 关闭 AI 接口后仍可演示学习完整闭环；
- 关闭事件接口后剧情继续；
- 网络恢复后事件能够补发；
- 重试不产生重复事件；
- 关闭语音后剧情继续；
- 知识星系加载失败不白屏；
- 手机端主要按钮可操作；
- 反馈提交失败时用户内容不丢失。

# 五、数据任务

## 数据保留任务

定时处理：

- 删除过期原始事件；
- 清理失效管理员会话；
- 清理过期匿名删除请求记录；
- 压缩长期聚合统计；
- 保留公开愿望和产品回复；
- 记录清理任务审计。

## 数据备份

- 生产数据库定期备份；
- 管理员和愿望状态优先保护；
- 备份加密；
- 恢复流程定期验证；
- 备份保留周期与正式隐私政策一致。
